# 06_キャラクター・ジョブ

> **ジョブ刷新（2026-06-26 オーナー決定）:** 基本ジョブは **5 種**（ソードマン / レンジャー / ヴァンガード / アルケミスト / ビーストテイマー）。上位・下位職は設けない。世界観 SSOT は `world/09_Jobs.md`（本書は数値・実装仕様の SSOT）。下記「基本ジョブ（戦士/騎士/盗賊/狩人/魔術師）」「上位ジョブ候補」は **旧仕様（Superseded）**。実装ジョブ（warrior/guardian/scout）からの移行は将来 Task。
>
> **ジョブの設計思想（Combat Vision）:** ジョブはスキルリストではなく **AI 行動思想** を決定する（`26_CombatVision.md`）。

## パーティ

人間 **最大4名** 編成（`GameState.ACTIVE_PARTY_SIZE`）＋随伴ペット1（枠外・共有EXP）。

想定ロール

- 前衛
- 後衛（陣形スロット）
- ペット（常時前衛相当・装備なし）

## キャラクター成長

レベル制。強さの大部分は装備に依存する（レベルは HP/ATK の平坦加算）。

レベル範囲：**Lv1〜99**（ソフトキャップ Lv50／マスタリー Lv51〜99）。

## レベル制（実装 — P3-D035a / P3-LV-099 / P3-BAL-EXP-001）

| 項目 | 値 |
|---|---|
| EXP 付与 | 撃破積立（`run_exp_reward`／メンバー別）。生存者のみ。完走時 +25%（CLEAR）。撃破に **×1.5**（`COMBAT_KILL_EXP_MULT`） |
| 必要 EXP | `exp_to_next(L) = 100 × L`（Lv1→2=100, 2→3=200 …）。**据置** |
| 上限 | **Lv99**（Lv51〜99は逓減成長・スキル習得はLv50まで） |
| 成長 | **`BalanceConfig`**: Lv1〜50 は +48 HP / +16 ATK / +8 DEF、Lv51〜99 は +24 HP / +8 ATK / +4 DEF（×`STAT_SCALE`）。**キャラ別倍率**は `CharacterGrowthRates`（P3-BAL-GROWTH-H1-001） |
| 推奨Lv | ダンジョンの「推奨レベル」は **勝率の目安**（必須条件ではない） |
| 未対応 | 個別 EXP・ジョブ別成長係数（将来） |
| 適用点 | HP=`CombatController._init_party_hp`、ATK=`RosterUiHelper` / ダメージ計算（affix flat と同段） |
| 永続化 | `Adventurer.exp` を SaveManager で保存 |
| 実装 | `scripts/systems/LevelSystem.gd` |
| 表示 | 拠点メンバー行に `Lv/EXP`、Result にレベルアップ通知 |
| 設計メモ | 推奨Lvは勝率帯の目安。①初回通しは推奨より低Lv到達が前提（周回で追いつく） |

## ジョブ進化（到達形 — 実装 P3-D037 / P3-D052）

> **βオミット（P3-JOB-EVO-OMIT-001 / 2026-07-27 オーナー GO）:**  
> `Constants.JOB_EVOLUTION_PLAYABLE=false`。UI・新規認定・専門深化・昇格特質・着色は無効。  
> `JobData`／`is_evolved` セーブ項目は残置（再有効化用）。

進化先名は `world/09_Jobs §4` / P3-D048 確定（単線）。本節は数値・実装（再有効化時）。

| 項目 | 値 |
|---|---|
| プレイ | **OFF**（`JOB_EVOLUTION_PLAYABLE`） |
| トリガー | 英雄管理／ギルド認定（Lv30 到達後）※オミット中は不可 |
| 必要 Lv | **30**（`JobData.evolution_level`） |
| 効果モデル | **専門深化**: 進化後補正 = `1.0 + (基礎補正 - 1.0) × 1.3`（HP/ATK/DEF） |
| 昇格特質 | 職ごと常時パッシブ2つ（`EvolutionTraits.gd`）※オミット中は不発 |
| 永続化 | `Adventurer.is_evolved`（bool）を SaveManager で保存（残置） |
| 到達形名 | swordsman→ソードセイバー / ranger→スナイパー / vanguard→パラディン / alchemist→セージ / beast_tamer→ビーストロード |
| 実装 | `JobEvolution.gd` / `EquipmentScene` / `GuildScene` |

> `job_id` は進化後も不変（到達形は派生表示）。装備の preferred_weapon 判定等は基本職のまま。

## ジョブと AI 行動思想（Combat Vision — P2-D166）

実装済みジョブ（`resources/jobs/`）は、戦闘 AI の**行動思想**を表す。スキルは補助であり、主役は立ち回りである。

| id | 表示名 | AI 思想（Vision） | 実装状態 |
|---|---|---|---|
| `swordsman` | ソードマン | 前線で被弾を引き受ける近接 | データ + 戦闘 modifier 接続済（簡易ヘイト=前衛） |
| `ranger` | レンジャー | 弓で後方から火力 | 同上（preferred=bow） |
| `alchemist` | アルケミスト | 杖で魔法ダメージ+デバフ（呪い） | 同上（preferred=staff、回復/バフは MVP 外） |

> **実装移行（2026-06-26 / P3-D034）:** 旧 `warrior/guardian/scout` を `swordsman/ranger/alchemist` に置換。セーブ移行は `SaveManager._JOB_MIGRATION`（warrior→swordsman / scout→ranger / guardian→alchemist）。スプライトは旧 CHR_* をプレースホルダ流用（オーナー作画待ち）。簡易ヘイトは `guardian` 起点から `swordsman`（前衛）起点に変更。

将来候補: ヴァンガード（盾前衛）・ビーストテイマー — `world/09_Jobs.md`

**現行 Alpha:** Job modifier は stat に接続済み。位置・ターゲット AI は未接続（CombatTimer 抽象戦闘）。
