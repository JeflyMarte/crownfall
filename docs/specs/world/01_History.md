## 1. 時代区分（年表）

世界の歴史は、大きく五つの時代に分けて語られる。

正確な年代は多くが失われ、現代では遺跡や碑文、断片的な記録をもとにした復元が行われている。

| 時代 | 概要 |
|---|---|
| **先王時代（伝承）** | 九王時代より前にあったとされる、起源不明の超古代。各地に「世界遺産」と呼ばれる巨大構造物を遺したと伝わるが、確かな記録はほとんど残っていない。九王時代との境界も定かではない。白王の名が断片的に現れるが、実在は確かめようがない。 |
| **九王時代** | 九人の王がそれぞれ異なる理念を掲げ、世界各地で文明を築いた時代。交流と発展が続き、多様な知識と技術が花開いた。王遺産・街道・書庫・星炉など、後世が拾う遺産の多くはこの時代に起源を持つとされる。 |
| **王国時代** | 九王の思想を継いだ諸王国が広く栄えた時代。中央王統アステリアがゆるやかな盟主となり、街道や港、市場、学術機関が整備された。人々の営みは最も豊かだったと伝えられるが、末期には盟議の決裂と交流網のほころびが始まる。 |
| **九王戦争** | 王国時代を終焉へ導いた大戦。発端・経過・勝者はいずれも諸説。灯断ちの年を経てアステリアの長夜に至り、統一王権は倒れた。 |
| **静寂の時代** | 人類文明が衰退した後の長い空白。自然は遺構を覆い、戦後生態系が各地で形成された。人口は城壁の内側に縮み、野外は危険と調査の領域となった。 |
| **探索者の時代** | 現在。探索者たちは遺物回収と生態調査を通じて、失われた歴史を少しずつ記録し直している。ギルド暦 G.118。モーンゲート調査が本格化する入口にあたる。 |

## 1.5. 先王時代と世界遺産（伝承）

九王時代より前にも、何者かが世界に痕跡を残していた。

各地に点在する起源不明の巨大構造物は **世界遺産（World Monument）** と呼ばれ、九王時代の建造物とは技術も様式も異なる。誰が、いつ、何のために築いたのかは分かっていない。

古い伝承には、九王より前に「継承」を司ったとされる **白王（the White King）** の名が断片的に現れる。`白王の神殿` はその信仰の跡とされるが、白王が実在したのか、何者だったのかは確かめようがない。

先王時代は、記録ではなく伝承の中にだけ残された、最も古い空白である。

## 2. 九王戦争（統一文案・諸説）

九王戦争は、王国時代を終わらせた大戦として知られている。

しかし、その実像は現代までほとんど伝わっていない。

ある地域では九人の王自身が最後の戦いを繰り広げたという。

別の地域では、九王の名を継いだ諸王国同士の戦争であったと語られる。

さらに、戦争そのものよりも、その後に訪れた文明の急速な崩壊こそが本当の災厄だったという伝承も残されている。

一致しているのは、戦争の後に王国時代は終わり、人類文明は急速に姿を消したという事実だけである。

戦争の真相は今も失われたままであり、探索者が各地で見つける記録も互いに食い違うことが少なくない。

### 経過（諸説の骨格）

確かな年表は残っていないが、各地の伝承を重ねると、戦争はおおよそ三つの段階を経たと考えられている。

**発端（諸説）** — 何が戦争を引き起こしたのかについては、複数の説が伝わる。

- 王都に伝わる「継承」を巡って諸王が対立したという説。
- 国境と資源を巡る、ありふれた領土争いだったという説。
- 戦争そのものよりも、同時期に起きた未知の災厄が引き金だったという説。

いずれの説も決め手を欠き、地域によって語られる原因は大きく異なる。

**拡大** — 一度始まった争いは、諸王国を次々と巻き込んでいった。中央の王都アステリアが担っていた諸国の盟主としての機能は急速に失われ、各地は孤立した。街道は寸断され、王国時代を支えた交流網は崩れていった。

**終息と崩壊** — 戦争がどのように終わったのかも定かではない。勝者を記す記録は存在しない。むしろ多くの伝承は、戦争の後に訪れた **急速な文明崩壊** こそが本当の災厄だったと語る。人口は激減し、技術と知識は維持する者を失い、静寂の時代が始まった。

### 伝承年表（復元 / 諸説）

ギルド記録部が各地の碑文・写本・口承を突き合わせて復元した、崩落前後の大まかな流れである。**年代はすべて復元値（諸説）であり、地域の記録は互いに食い違う**。`§7` の紀年法（崩落後 A.F. / 崩落前 B.F.）に従う。

| 時期（復元・諸説） | 出来事 | 備考・接続 |
|---|---|---|
| B.F. 約20年 | **最後の盟議** — 諸王（諸王国）が盟約の地アイゼンプレインに集った最後の会議。決裂し、中央王統の盟主機能が揺らぎ始めたとされる転機 | 信義王アウレクス／盟約の地（`07`）。決裂の理由は諸説 |
| B.F. 約15〜5年 | 諸国の対立が拡大。王の大街道の要所が次々に寸断され、各地が孤立へ向かう | 巡礼王ルミナスの街道網が機能を失う |
| B.F. 数年 | **灯断ちの年** — 街道の宿駅・神殿の灯が各地で絶え、交流網が事実上崩壊した年と語られる | 「灯火の信仰」（`08_SeekersGuild §13`）・灯守組合の起源（`14`）に連なる |
| **A.F. 0年（崩落）** | **アステリアの長夜** — 王都アステリアが失われた夜。統一王権は倒れ、王のいない世界が始まった（＝崩落 / 作品名 Crownfall の由来）。残るのは「王冠は倒れた」の一文のみ | HE-007／継承王カエルム（`13`）。記録は失われた王都の記録者セレスの手による |
| A.F. 0〜約200年 | 静寂の時代。人口激減・知識喪失・遺構の自然化が進む | `§6`／`03_Ecology` |
| A.F. 約180年 | 探索者ギルドの前身が発足。調査と記録の共有が始まる | HE-008 |
| A.F. 約300年（現在＝G.118） | 探索者の時代。モーンゲート調査が本格化し、物語が始まる | HE-009／`§8` |

> 「最後の盟議」「灯断ちの年」「アステリアの長夜」はいずれも各地の伝承に現れる通称であり、同じ出来事が別名で語られることもある。確かな史実としては確定していない。中核の謎（崩落の真因等）の真相はここでも記さない（`10_LoreDelivery §9`）。

### 通称事件の詳細（復元・諸説）

#### 最後の盟議（B.F. 約20年）

盟約の地 **アイゼンプレイン** に、諸王（あるいは諸王国の代表）が集った最後の会議とされる。信義王アウレクスの理念——約束と盟約——を象徴する場だったが、決裂の理由は伝わらない。

- **継承説** — 王都に伝わる「継承」を巡って対立した。誰が次の盟主か、何を継ぐかが噛み合わなかった、という。
- **国境説** — ありふれた領土と資源の争いが、盟主機能の弱体化に乗じて爆発した、という。
- **災厄先行説** — 会議の前後に未知の災厄の兆候があり、会議は原因ではなく症状だった、という。

議事録は残っていない。残るのは「決裂した」という結果と、その後に街道が寸断されていった過程だけである。図鑑 HE-011 はこの事件の要約である。

#### 灯断ちの年（B.F. 数年）

街道の宿駅・神殿・灯台の灯が、各地で相次いで絶えた年とされる。巡礼王が結んだ交流網が事実上崩壊し、隊商は途切れ、地方は孤立へ向かった。

- 灯が「消された」のか、「保てなくなった」のかで伝承が分かれる。
- 灯火の信仰と灯守の習わしは、この記憶を「絶やすな」という作法へ変えた、と記録部は見る。
- ブラックショアの灯台銘「潮が引くとき灯を上げ、満ちるとき火を継げ」は、同じ感覚の地方変奏として読まれることがある。

図鑑 HE-010 はこの年の要約である。真相（誰が・なぜ）は記さない。

#### アステリアの長夜（A.F. 0年／崩落）

王都アステリアが失われた夜の通称。統一王権は倒れ、王のいない世界が始まった。作品名 Crownfall の由来でもある。

- 残る碑文の多くは「王冠は倒れた」の一文で止まり、滅びたとは書かない。
- 記録者セレスの手稿（アステリア陥落録）は、崩落の音を書き留め続けたが、勝者の名を書けなかった、と伝わる。
- 「長夜」は一晩だったのか、数日の闇だったのか、地域で呼び名が違う。

図鑑 HE-007 はこの夜の要約である。崩落の真因は中核の謎として余白のまま残す。

## 3. 九王（Nine Kings）

九王は、それぞれ異なる理念を掲げ、人類文明の礎を築いたと伝えられる。

現代では英雄というより、一つの時代を象徴する存在として語られることが多い。

| 称号 | 名 | フック |
|---|---|---|
| 開拓王 | エルディオン（Eldion） | 既知世界の外縁を記録した王。未知へ道を開いた。 |
| 守護王 | ヴァルケイン（Valkein） | 王盾と境界の思想を築き、守ることの意味を示した。 |
| 学識王 | セラディス（Seradis） | 大書庫を築き、知識を集め、封印した王。 |
| 信義王 | アウレクス（Aurex） | 約束と盟約を国家の礎とした王。 |
| 巡礼王 | ルミナス（Luminas） | 街道網の整備を進め、人と文化を結びつけた王。 |
| 鍛冶王 | オルグラン（Orgran） | 星炉を築き、数多くの王遺産を鍛造したと伝わる。 |
| 海統王 | ネレイオス（Nereios） | 潮境を治め、海路を統治した王。 |
| 森護王 | シルヴァリア（Sylvaria） | 森林と生命循環を守り、世界樹を敬った王。 |

九王にまつわる逸話は地域ごとに姿を変え、史実と伝承を明確に区別することは難しい。

## 3.5. 王国時代の諸王国

王国時代は、九王の思想を継いだ諸王国が各地に栄えた時代である。

中央の王都アステリアがゆるやかな盟主として諸国を結び、それぞれの王国が異なる理念と産業を担っていた。以下は、現在までに復元された主要な諸王国の概略である（地理は `07_Geography`）。

## 4. 九英雄（Nine Heroes）

九英雄は王ではなく、人々の営みを支えた人物として各地の伝承に残る。

その功績は戦いだけでなく、探究、記録、鍛造、航海、継承など多岐にわたる。

| 称号 | 名 | フック |
|---|---|---|
| 地平の探求者 | アステル | 地図の余白を埋め、未知を既知へ変えた探求者。 |
| 王遺産の守り手 | エレナス | 王遺産を継承物として扱う倫理を示した人物。 |
| 深淵を踏破した者 | リュシアン | 深淵を恐怖ではなく知識の対象として記録した。 |
| 灯火を継いだ巫女 | イリア | 戦乱の中でも灯火と祈りを絶やさなかった。 |
| 星屑の鍛冶師 | ラグナ | 星屑鍛造の基礎を築いた鍛冶師。 |
| 失われた王都の記録者 | セレス | 崩壊する王都を最後まで書き留めた記録者。 |
| 竜と盟約を結んだ者 | カイル | 「竜」と呼ばれた巨大生物との距離を見出したと伝えられる。 |
| 世界の果てを見た航海者 | マレク | 海の彼方へ航海し、帰還後に多くの記録を残した。 |
| 名を残さなかった継承者 | （無名） | 名ではなく意思だけを後世へ託したとされる存在。 |

九英雄もまた、九王と同じく史実と伝承が重なり合っている。

彼らが実在したかどうかよりも、その思想が各時代へ受け継がれたことが重要視されている。

### 各英雄の伝承（断片）

以下は各地に残る伝承をまとめたものであり、確証のない記録を含む。

**地平の探求者 アステル** — 既知世界の外縁を歩き、地図の余白を埋め続けたと伝わる。探索者ギルドの三大任務「地図更新」は、その姿勢を継いだものだとされる。

**王遺産の守り手 エレナス** — 王遺産を「誰かの所有物」ではなく「後世へ受け継ぐべき記録」として扱う倫理を示した。ギルドに伝わる言葉「遺産を持ち帰るな、歴史を持ち帰れ」の源とされる。

**深淵を踏破した者 リュシアン** — 地下深部や未知の領域を、恐怖ではなく調査対象として記録した。危険区域へ踏み込む生態調査の規範を築いたと語られる。

**灯火を継いだ巫女 イリア** — 戦乱の中でも灯火と祈りを絶やさなかった。人々は彼女を「灯火を継いだ者」と呼び、その姿は今も継承の象徴として語られる。

**星屑の鍛冶師 ラグナ** — 星屑鍛造の基礎を築いた。鍛冶王オルグランの星炉の技を受け継いだとされ、現代の鍛冶もその系譜に連なると伝わる。

**失われた王都の記録者 セレス** — 崩壊していく王都を、最後まで書き留め続けた。九王戦争と王都陥落について残る数少ない記録は、その手によるものだという。

**竜と盟約を結んだ者 カイル** — 「竜」と呼ばれた巨大生物と、戦うのでも従えるのでもない距離を見出したと伝わる。人と巨大生物の関係を探る者たちが、その名を引き合いに出す。

**世界の果てを見た航海者 マレク** — 海の彼方へ航海し、帰還後に多くの記録を残した。既知世界の外縁や遠い海域の伝承の多くは、彼の航海録に由来するとされる。

**名を残さなかった継承者（無名）** — 名ではなく意思だけを後世へ託したとされる。確かな記録は何も残っていないが、「次の者へ受け渡す」という思想そのものを体現した存在として語り継がれている。

## 5. 各時代の暮らし・遺構（プレイヤーが遺跡で出会う痕跡）

探索者が目にする遺跡は、戦争そのものではなく、人々が確かに暮らしていた痕跡である。

**九王時代**の遺構には、巨大な石碑や境界標、初期の街道跡が残されている。

**王国時代**では、市場跡、農地、水路、港、工房、書庫など、人々の日常を感じさせる建造物が多く見つかる。

**九王戦争**の痕跡として残るのは、崩壊した城壁、焼失した街並み、放棄された砦などであり、その原因を語る記録は少ない。

**静寂の時代**には、人の手を離れた建造物へ植物が根を張り、野生動物が棲み着き、遺構は自然の一部となった。

そして**探索者の時代**。

新たに立てられる標識や調査記録は、未来の誰かに向けた新しい歴史の断片となっていく。

探索者が持ち帰る記録は、小さな発見に過ぎない。

だが、その積み重ねこそが、失われた文明を再び一つの歴史として結び直していく。

## 6. 静寂の時代と都市の興亡

九王戦争の後、世界は長い静寂に包まれた。

### 静寂の時代の変遷

人口は激減し、街道の維持は途絶え、都市の多くは放棄された。人の手を離れた建造物には植物が根を張り、野生動物が棲みつき、遺構は少しずつ自然の一部へと変わっていった。

旧文明の技術は、それを扱う者を失って忘れられた。記録は散逸し、歴史は伝承の中にだけ残された。

一方で、自然はその空白を埋めるように再生した。各地で新たな生態系が形成され、生物は旧文明の遺構すら取り込みながら独自の進化を遂げていった（戦後生態系 / `03_Ecology`）。

やがて、点在して生き延びた共同体は、危険な世界で生き抜くために調査と記録を共有し始めた。それが後の **探索者ギルド**（`08_SeekersGuild`）の前身となり、静寂の時代は緩やかに **探索者の時代** へと移り変わっていった。

### 都市の興亡

| 都市 | 帰結 | 補足 |
|---|---|---|
| 王都アステリア | 廃墟 | 中央王統の都。地下にモーンゲート |
| レッドフォージ | 廃墟 | 鍛冶諸侯連合の都 |
| シーゲート | 存続 | 海洋連合の港。海路の名残として機能 |
| グリーンホロウ | 存続 | 森の盟約国の集落として残る |
| フロストウォール | 存続 | 北の山岳都市。辺境開拓諸侯の名残 |
| アイアンヘイブン | 新設 | 戦後に築かれた探索者都市。現在のプレイヤー拠点 |

廃墟となった都は探索の主な舞台となり、存続した都市は探索者たちの活動を支える。そして戦後に生まれたアイアンヘイブンが、失われた世界を再び結び直す拠点となっている。

## 7. 暦と紀年法

王国時代に使われていた正式な暦は、静寂の時代の知識喪失とともに失われた。

現在の年代の数え方は二つの層に分かれている。長い時間を語るための **崩落後（A.F.）** と、日々の生活に使う実用的な **ギルド暦（G.）** である。

### 紀年法（二層）

| 層 | 名称 | 起点 | 性質 |
|---|---|---|---|
| 長期尺度 | **崩落後（After the Fall / A.F.）** | 王都アステリア崩落（＝九王戦争の終焉） | 学者が用いる。記録散逸のため年数は不確定（諸説） |
| 実用暦 | **ギルド暦（Guild Calendar / G.）** | 探索者ギルドの創設 | 現行の公的暦。日付・契約・調査記録に用いる |

- **崩落（the Fall）** とは、王都アステリアが失われ王国時代が終わった出来事を指す。万人が知る歴史の基準点だが、そこから何年が経ったのかは正確には分からない。
- 一般に **崩落後およそ三百年（諸説 250〜340 年）** が経過したとされ、そのうち静寂の時代がおよそ二百年を占めたと考えられている。
- ギルド創設＝崩落後 約180年（推定）。**現在はギルド暦 118 年（G.118）**＝崩落後 約300年にあたる。
- 崩落以前（九王時代・王国時代）の年代は、ほとんどが「崩落前（B.F.）」として概数でしか語れない。

> 年代はすべて復元値である。探索者が見つける碑文や記録は、しばしば互いに食い違う。確かな数字よりも「崩落の前か後か」が重視される。

### 暦の構成（ギルド暦）

ギルド暦は、静寂の時代の末期にギルドが天体観測をもとに再建した実用暦である。

| 単位 | 構成 |
|---|---|
| 1 年 | 12 ヶ月＝360 日 |
| 1 ヶ月 | 30 日＝3 **旬（じゅん）** |
| 1 旬 | 10 日（王国時代の「週」に代わる区切り） |

月名の多くは王国時代に失われ、ギルドは月を番号（第一月〜第十二月）で呼ぶ。古い月名は断片的にしか残っていない。

### 四季と「澱みの季」

四季はそれぞれ三ヶ月ずつで巡る。戦後の生態系では季節が生物の移動・繁殖・活性を強く左右するため、探索者は季節を読んで調査計画を立てる。

加えて、地域によっては晩秋から初冬にかけて、地下や遺構で **闇のエルダ（瘴気）** の活性が高まる時期があり、これを **澱みの季（よどみのとき）** と呼ぶ。澱みの季には危険な生物が活発化し、深部探索は警戒される。確かな仕組みは分かっておらず、これも観察と記録の対象である（`03_Ecology §6`）。

### 時計と時間感覚

王国時代には精緻な歯車式の時計技術が存在し、街道沿いの都市には時計塔が築かれていたと伝わる。現在もごく一部の遺物時計が動き続けており、ギルドの時刻の基準となっている。

一日は夜明け・日中・黄昏・夜のおおまかな区切りで語られることが多い。なお、地下遺構で時間感覚が狂うのは怪奇現象ではなく、光の欠如や、歯車状の羽を持つ生物（クロックモス）の羽音など、自然に説明できる要因によるものとされる。

## 8. 現在の情勢（探索者の時代の"今"）

物語が始まるのは、静寂の時代がゆるやかに終わり、探索者の時代がしばらく続いたころである。

### 安定の途上

探索者ギルドと隊商網のおかげで、点在する都市はかつてより安全に結ばれるようになった。人々の暮らしは少しずつ落ち着きを取り戻しつつある。

とはいえ、安全なのは城壁の内側＝**安全圏**だけである。城壁の外に広がる **野外圏** は依然として危険であり、世界の大半はまだ調べ尽くされていない。世界は救われた後の世界ではなく、ようやく調べ直され始めた世界である。

### なぜ今、モーンゲートか

戦後に築かれた **アイアンヘイブン** は、中核都市へと成長し、いまや本格的な調査の前線基地となった。

その最寄りに眠るのが、旧文明の首都・王都アステリアの地下に広がる **モーンゲート** である。王都由来の遺物が豊富に残るこの地下は、遺物回収の最前線として以前から注目されてきた。

近年、その地下で生物の活動が活発化している兆候が観測された。鉱物化適応の個体が増え、**澱みの季**（§7）にはその傾向がいっそう強まる。ギルドはこれを重要な調査対象と判断し、新たな調査隊の派遣を決定した。

> これが、ゲーム開始時の状況である。プレイヤーの隊は、この機に編成された調査隊の一つであり、最初の調査地としてモーンゲートへ向かう（`05_Biomes §3`）。

### 動きつつある関心

探索者たちの間では、いくつかの関心がゆっくりと広がっている。

- 次の大規模調査地として、西の大森林 **ヴェルディア（囁きの森）** への関心が高まっている（`05_Biomes §3.2`）。
- 辺境では、生きた **古龍種** を見たという噂が絶えない（`04_Classification §5`）。
- 価値ある遺物の出どころをめぐり、商人や各支部のあいだに静かな駆け引きがある。
- ごくまれに、王冠や"九王の遺産ではない何か"に触れる古い記述が見つかり、記録部を密かにざわつかせている（真相は語られない / `10_LoreDelivery §9`）。

### プレイヤーの隊の立ち位置

プレイヤーが率いるのは、選ばれし英雄の一行ではない。

ギルドから **調査許可等級**（`08_SeekersGuild §9`）を得て活動を始めたばかりの、新たな調査隊である。彼らは世界を救うためにではなく、いまの社会に必要とされて野外圏へ送り出される。

その小さな一隊の積み重ねが、やがて失われた世界の輪郭を、少しずつ描き直していく。

既知世界の外縁を歩き、地図の余白を既知へ変えたと伝わる王。理念は開拓。辺境開拓諸侯（北・ノースリーチ／フロストウォール）を治め、黎明の羅針盤と王剣レクスを遺したとされる。征服ではなく「まだ誰も記していない場所がある」という指針そのものを象徴し、その姿勢は九英雄・地平の探求者アステルを経て、探索者ギルドの三大任務「地図更新」へ受け継がれた。北境は最も早く離散したが、山岳都市フロストウォールに開拓の気風が残ると語られる。

# HE-014 学識王セラディス

## Overview

各地の知識を大書庫——王立図書院——へ集め、記し、時には封じた王。理念は知識。叡智の書庫鍵と叡智の杖ノエシスを遺したとされる。錬成の体系化もその学府に連なると語られ、現代のアルケミスト系譜の遠い源とされる一方、「集めた知のいくつかをあえて封じた」という伝承が残る。何を、なぜ封じたのかは伝わらず、ミストフェンの沈没書庫や封じの碑文は、その問いへの入口として扱われる。

## Overview

東の山稜に星炉を築き、数多の王遺産を鍛えたと伝わる王。理念は鍛造。鍛冶諸侯連合（レッドフォージ）を治め、星炉の槌と星鍛槌グランフォージを遺したとされる。「受け継がれて使われ続けるものこそ価値がある」という信条は、後世の探索者ギルドの言葉と遠く響き合う。九つの王遺産に同じ王冠の紋様が宿るのは「九つはひとつの炉より」だと職人は言うが、炉に火を入れた者の名はどの記録にも残っていない。技は九英雄・星屑の鍛冶師ラグナを経て赤鉄の工房へ連なるとされる。

# HE-020 継承王カエルム

## Overview

中央の王都アステリアにあって、諸国をゆるやかに束ねた王統の長。理念は継承。「次の者へ」受け渡すことを統治の核に据え、継承の書と継承剣レガートを遺したとされる。王位や領土ではなく「次へ渡す」という原理そのものを記した、と伝わる。最後の継承者として語られることが多いが、何を誰へ継ごうとしていたのかは崩落とともに途絶えた。各地の碑文に残る「王冠は倒れた。しかし滅びていない」は、この問いへの入口として記録部が扱う。真相は記さない。

# HE-049 灯火の信仰

## Overview
