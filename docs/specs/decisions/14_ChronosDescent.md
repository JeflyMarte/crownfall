# 時環の共鳴龍　降臨／時王の霊廟（P3-DG-CHRONOS-DESCENT-001）

**Status:** SSOT（Decision 承認済）  
**Approved:** 2026-07-26（オーナー GO）  
**Related:** `13_ChronosWaveDragon.md`（Boss 設定・戦闘値）

## 概要

イベント枠の **クロノス降臨ダンジョン**。  
バナー見出しは **時環の共鳴龍　降臨**。実際に潜る名称は **時王の霊廟**（ノーマル／ハード／ナイトメア）。

征討 `mourngate_deep`（未踏査層）は本 Decision で **本イベントへ置換**（id は `chronos_mausoleum` を正とし、旧 `mourngate_deep` はエイリアスまたは移行削除）。

## 表示

| 層 | 文言 |
|---|---|
| バナー／タイトル | **時環の共鳴龍　降臨** |
| 選択行（N） | **時王の霊廟　ノーマル** |
| 選択行（H） | **時王の霊廟　ハード** |
| 選択行（NM） | **時王の霊廟　ナイトメア** |

UI: イベントタブ。Featured バナー下に **難度3行**（グローバル Hard タブ非依存でも可。実装は難度3行を優先）。

## 出現スケジュール

| # | 決定 | 内容 |
|---|---|---|
| 1 | **出現** | **毎日** JST **0:00 / 3:00 / 6:00 / 9:00** から各 **1時間**（0–1時・3–4時・6–7時・9–10時） |
| 2 | **進行解放** | **なし**。新規から挑戦可（⑤クリア不要）。ウィンドウ外は未開放 |
| 3 | **ウィンドウ外** | 一覧に出すが選択不可。「次の出現 HH:00」表示 |
| 4 | **日次回数** | **制限なし**（出現時間内は再挑戦可）。失敗・リタイアも可 |
| 5 | **デバッグ** | 時刻オーバーライドで常時開放可（既存曜日デバッグと同型） |
