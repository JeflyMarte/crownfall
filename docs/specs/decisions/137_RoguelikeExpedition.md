## 0. 一言

所持キャラ **1人** を **Lv1** から選び、**ランダム50F** を踏破。**5Fごと** に **遠征専用装備** を選んで装備。**レジェンド／ミシック率は遠征専用で大幅増**。  
装備 id は **本編・ガチャ・深層・降臨では一切出ない**。**30F中ボス**・**50Fクリア**・**キャラ別ビンゴ**。

## 4. 遠征専用装備プール（専売）

### 4.1 原則

| ルール | 内容 |
|---|---|
| **id 空間** | `rogue_<theme>_*`（武器／防具／装飾）。**既存 id の複製禁止** |
| **出所** | **遺跡遠征の5Fステーション／F30/F50 のみ** |
| **除外** | 本編ドロップ・宝箱・鍛冶・錬成・封蔵・深層・降臨・放浪・`MythicLoot`・灰冠・ビルドL 既存 id |
| **恒久化** | **F50 初回クリア1点のみ**（§5.1）。それ以外のラン装備は **ラン終了で消失** |
| **図鑑** | 遠征専用タブ or 装備詳細に「遺跡遠征専売」バッジ |

### 4.2 カタログ規模（初版）

| 帯 | 目安 |
|---|---|
| 武器 | ジョブ×2〜3＋汎用 ≒ **20本** |
| 防具 | **12** |
| 装飾 | **12** |
| ミシック | **6**（クリア確定＋後半ステーション低確率） |
| レジェンド | **15**（中盤〜後半） |

数値・スキルは Impl 時調整可。**id と専売フラグが SSOT**。

## 5. レアリティ抽選（高L/M）

### 5.1 本編参考（対比用）

本編撃敗ドロップ重み（`DungeonController`）: COMMON120 / RARE45 / EPIC15 / **LEG1**（≒0.5%）。  
神話は **別枠1%**（`MythicLoot`・ボス再クリア）。

### 5.2 遠征ステーション — 帯別重み（**各候補1枠**）

| 到達F | ◇ | ◆ | ✦ | **L** | **神** |
|---:|---:|---:|---:|---:|---:|
| 5〜15 | 0 | 30 | 45 | **20** | **5** |
| 20〜25 | 0 | 15 | 35 | **40** | **10** |
| 35〜45 | 0 | 5 | 25 | **55** | **15** |

> **L＋神 ≒ 25〜70%**（帯で上昇）。本編比 **数十倍**。

### 5.3 ステーション内ルール

| ルール | 内容 |
|---|---|
| 3候補 | **最低1枠は Epic 以上** |
| 後半ブースト | F35+ で **3候補のうち1枠を Legendary 以上固定** |
| カテゴリ | 3枠のうち **武器1・防具1・装飾1** を基本（ジョブ武器優先重み） |
| pity | **8ステーションごと**に Legendary 未取得なら次ステーション **1枠 L 確定** |
| mythic pity | **3周（F50×3）クリアごと**に次クリア **ミシック確定** |

### 5.4 F30 / F50 確定

| タイミング | 付与 |
|---|---|
| **F30 撃破** | 遠征レジェンド **1確定**（ラン内装備・3候補→1） |
| **F50 初回クリア** | 遠征 **ミシック or レジェンド1** → **恒久 inventory** |
| **F50 2回目以降** | 魔晶石15〜30 ＋ 低確率で同プール（pity 10） |
