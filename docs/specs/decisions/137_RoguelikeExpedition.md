## 0. 一言

所持キャラ **1人** を **Lv1** から選び、**ランダム50F** を単独（＋ラン内仲間）で踏破する **ラン専用ビルド** モード。  
**10Fごと** に仲間・武器・回復等を選び、**30F中ボス**・**50Fクリア** で **遠征限定装備**。**キャラ別ビンゴ星** でやり込み。

## 3. ラン内ビルド（ピック）

### 3.1 ピック種別（F10／20／40）

プレイヤーに **3カード** を提示し **1つ選択**。

| 種別 | 効果 | 備考 |
|---|---|---|
| **仲間** | ラン専用助っ人1体加入（**最大パーティ4**＝本人＋仲間3） | プール＝助っ人／職テーマNPC。**恒久 roster には加えない** |
| **武器** | ラン専用武器1本（レアリティは F帯で段階上昇） | **恒久 inventory に直入れしない**。ラン中のみ装備 |
| **回復** | 生存者 **最大HP35%回復**（最低1） | 応急手当演出流用可 |
| **スキル**（任意4種目） | ラン専用スキル1本を **空スロット or 上書き候補** | Q1で3種固定なら **スキルは武器枠のサブ** でも可 |

> 本編「分かれ道三択」（次Fバフ）とは **別UI・別ロジック**。混在しない。

### 3.2 ラン専用状態（セーブ分離）

| キー（案） | 内容 |
|---|---|
| `rogue_run_active` | 進行中ラン有無 |
| `rogue_run_seed` | 再現用シード |
| `rogue_floor` | 現在F |
| `rogue_leader_id` | 選択キャラ id |
| `rogue_party` | ラン内メンバー（Lv／HP／仮装備／仮スキル） |
| `rogue_pick_history` | 取得ピック履歴（ビンゴ判定） |
| `rogue_checkpoint_floor` | 30F撃破済みなら 30 |

**禁止:** ラン武器・ラン仲間を `GameState.inventory`／`roster` に混在させない。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 50Fが長い | 1F短縮・F30 CP・スキップ禁止でも30分目安 |
| 本編ハクスラと競合 | 限定装備は別 id プール／ラン内装備は恒久化しない |
