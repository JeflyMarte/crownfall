- 各トピック **1ページ**（全5ページ）。スキップ可

| 項目 | 値 |

| フラグ | `GameState.tutorial_flags.hub_simple_guide_done` |

| 既存セーブ | マイグレーションで **済み扱い**（Continue では出さない） |

| 修復 | 進行済み（`stage_progress` あり）なのにフラグ欠落なら load 時に済みへ |
