# MVP詳細カード拡充（案A）

**Status:** Decision 承認済（2026-07-26 オーナー GO）  
**Task:** P3-UX-MVP-DETAIL-001

---

## 1. 目的

MVP画面の統計を厚くし、ロールの見せ場を出す。空欄・0表示を減らす。

---

## 2. 表示（案A）

- カード最大 **6**（2列グリッド）
- **値が 0 のカードは出さない**
- MVPスコアは引き続き非表示（選出専用）

### 候補（優先順・実数があるものだけ）

| キー | ラベル | 備考 |
|---|---|---|
| damage_total | 与ダメージ | 既存 |
| damage_max_hit | 最大ヒット | 既存 |
| kill_count | 撃破数 | 新規 |
| damage_taken | 被ダメージ | 新規 |
| ultimate_count | 必殺回数 | 新規（発動回数） |
| crit_count | 会心回数 | 新規 |
| heal_total | 回復量 | 既存（0なら非表示） |

---

## 3. 集計

`RunCombatStats` に上記フィールドを追加。戦闘フックで記録。

- 撃破: 味方攻撃で敵HP≤0（DoT撃破は対象外で可）
- 被ダメ: 敵攻撃／敵スキル／味方DoT被弾
- 必殺: 必殺プレゼン開始時に +1
- 会心: ダメージ記録時に critical なら +1

既存セーブ互換: 欠落キーは 0 扱い。

---

- MVP選出式の変更（damage + heal×0.5 据置）
- 全員ミニ表（案C）
