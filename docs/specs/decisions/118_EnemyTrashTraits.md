# 雑魚特性（パッシブ特殊能力）

**Status:** Decision 承認済（2026-08-09 — オーナー「ここまで GO」）  
**Impl:** 同ターン  
**関連:** `35_EnemyTrickySkills.md`（トリッキー＝スポット／本 Decision＝雑魚一律特性で別枠）

---

## 1. 方針

| 項目 | 内容 |
|---|---|
| 定義 | **パッシブ特殊能力**（スキル・ステ数値・通常/スキル軽減ではない） |
| 対象 | 本編プール雑魚＋放浪希少（エリート／ボスは後続） |
| 付与 | **1体につき必ず1つ**（`EnemyData.trait_id`） |
| 強さ | 読みを変える程度 |
| 見せ方 | 図鑑（戦闘データ）＋戦闘で特性発火の初回 `◇特性名` |
| 既存 | トリッキー／硬殻／幻障は据置。吸血は既存 `lifesteal_ratio` を特性表示と同期 |

---

## 2. カタログ（10種）

| ID | 表示名 | 効果 |
|---|---|---|
| `thorns` | 棘反撃 | 通常被弾時、攻撃者へ `敵ATK×0.25`（下限1）反射 |
| `death_nova` | 死に際 | 撃破時、生存パーティへ `敵ATK×0.35`（下限1） |
| `pack_rage` | 群れの怒り | 他敵撃破時、自身へ `enrage`（既存ステ） |
| `front_focus` | 前衛狙い | 前列優先ターゲット |
| `back_focus` | 後列狙い | 後列優先ターゲット |
| `lifesteal` | 吸血 | 与ダメの30%自己回復（`lifesteal_ratio`） |
| `touch_ailment` | 接触異常 | この敵へ通常攻撃した味方が25%で異常（種＝`on_hit_status_id`） |
| `low_hp_haste` | 瀕死加速 | HP30%以下でイニシアチブ×1/0.70 |
| `double_tap` | 追撃 | 通常2ヒット（2発目×0.40） |
| `skill_tax` | 重圧 | 命中時、対象の職スキルCD+2秒（必殺除外） |

---

割り付け表は相談時の推奨一覧どおり（①〜⑤＋放浪）。SSOT 実装は `CombatEnemyTraits.ASSIGNMENTS`。
