# ロックバイソン放浪化＋放浪の群れ混入（P3-BAL-ROCK-BISON-WANDER-001 / P3-BAL-WANDER-MIX-001）

**日付:** 2026-08-09  
**状態:** 承認（オーナー GO）

## 要旨

1. ロックバイソンを通常 `enemy_pool` 横断から外し、**他の放浪と同帯の出現率**にする。  
2. 放浪遭遇は単独置換ではなく、**章雑魚の群れにまぎれる**（例: 吸血ヒル／吸血ヒル／ダック）。

## 確定

| 項目 | 内容 |
|---|---|
| バイソン出現 | `WanderingEnemyConfig` に追加。基準率 **1.5%**（レイヴン／スカラベと同帯）。H/NM は既存倍率 |
| pool | メイン／寄り道／無限／征討から除去。**岩角の群れ道**と**境界廊**のみ pool 据置（イベント専用・岩鉄感） |
| フラグ | `rock_bison.is_wandering = true`（逃走なし） |
| 混入 | COMBAT で放浪成功時、通常群れを組んで**末尾スロットを放浪に差し替え**。単体抽選時も 2〜3 体パックを強制 |
| 例外 | **ビッグコズミックダック**／**影狩**は単独維持。裂け目ビッグ 1〜2 も据置 |
| ログ | 群れに放浪がいるとき `【放浪混成】` |

## 上書き

- `P3-BAL-ROCK-BISON-SPAWN-001/002` の「全非イベント pool＋重み抑制」→ 本 Decision が正（pool 横断を廃止）
- `P3-WANDER-001` の「放浪＝COMBAT 単独差し替え」→ 混入方式へ（ビッグ除く）
