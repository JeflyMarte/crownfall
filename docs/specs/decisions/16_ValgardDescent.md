# 境界の番　降臨／ストームクラウン境界廊（P3-DG-VALGARD-DESCENT-001）

**Status:** SSOT（Decision 承認済）  
**Approved:** 2026-07-26（オーナー GO・実装案どおり）  
**Related:** `15_ValgardGolem.md`（Boss 設定・戦闘値）

## 概要

イベント枠の **ヴァルガード降臨ダンジョン**。  
バナー見出しは **境界の番　降臨**。実際に潜る名称は **ストームクラウン境界廊**（ノーマル／ハード／ナイトメア）。

征討 `storm_crown_ruins`（境界遺構ストームクラウン）は本 Decision で **本イベントへ置換**（id は `valgard_boundary` を正とし、旧 `storm_crown_ruins` は削除）。

| # | 決定 | 内容 |

| 1 | **出現** | **毎日** JST **1:00 / 4:00 / 7:00 / 10:00** から各 **1時間**（1–2・4–5・7–8・10–11時） |
