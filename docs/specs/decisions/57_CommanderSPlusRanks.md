# 指揮官等級 S+（無限段）

**Status:** Decision 承認済（2026-08-02 — オーナー「案Aでgo」）  
**Impl:** `P3-CMD-RANK-SPLUS-001`  
**関連:** P3-CMD-RANK-CURVE-003／P3-CMD-RANK-REWARD-001／`CommanderProfile`

---

## 1. 方針

S（2200）到達後も調査点（SP）で等級が伸びる。表記は `S+1`, `S+2`, …

| 原則 | 内容 |
|---|---|
| D〜S | 閾値・意味・金印・称号枠は据置 |
| S以降 | **+400 SP** ごとに1段（無限） |
| 報酬 | 各 S+n に薄い到達手当（Gold／石）。数段ごとに称号 |
| 既存S | SPから自動で S+n 表示。未付与段のみギフト |
| TopBar | 次の S+n までバー（「最大等級」固定を廃止） |

---

## 2. 閾値

| 等級 | SP |
|---|---|
| D〜A | 据置（0 / 400 / 900 / 1500） |
| S | 2200 |
| S+n | `2200 + n × 400`（S+1=2600, S+2=3000, …） |

---

## 3. S+n 到達手当（薄め）

| 項目 | 値 |
|---|---|
| Gold | 1500 |
| 招待石 | 15 |
| 素材 | S+5 / S+10 / … の5の倍数で `base_ore×10` + `relic_shard×5` |
| 称号 | S+5「深域調査官」／S+10「永続調査官」（コスメ） |

---

## 4. 表示

- アイコン: S アイコン流用。グレフは `S+n`
- 副題: 「継続調査許可」
- ランクアップ祝辞: 既存オーバーレイを S+n でも使用
