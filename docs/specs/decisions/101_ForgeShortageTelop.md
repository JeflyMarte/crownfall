# 鍛冶不足テロップ（P3-UX-FORGE-SHORTAGE-TELOP-001）

**ID:** P3-UX-FORGE-SHORTAGE-TELOP-001  
**日付:** 2026-08-09  
**状態:** 承認（オーナー GO）

## 確定

生産／炉研ぎ／錬成で Gold または素材が足りないとき、画面中央に「〇〇が足りません」テロップを出す。

| 不足 | 文言例 |
|---|---|
| Gold | ゴールドが足りません |
| 素材 | 基礎鉱が足りません（具体名） |

- Gold／素材不足だけでは主ボタンを disable しない（押下でテロップ）
- 未解放・袋満杯・上限到達など他理由は従来どおり disable／拒否
