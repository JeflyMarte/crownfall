# アルケミスト治癒ナーフ（CD増・大治癒全体化）

**ID:** P3-BAL-ALCHEMIST-HEAL-001  
**日付:** 2026-08-05  
**状態:** 承認（オーナー指示）

## 要旨

治癒の回転が強すぎた。CDを伸ばし、大治癒は単体緊急から**全体の薄め回復**へ役割をずらす。

## 決定

| スキル | 変更前 | 変更後 |
|---|---|---|
| `mend`（治癒） | 単体最傷 20%／CD **5.0** | 単体最傷 20%／CD **8.0**（威力据置） |
| `salve_burst`（大治癒） | 単体最傷 **32%**／CD 8.5 | **全体各員 12%**／CD **12.0** |
| `grand_elixir` | 全体 16%／CD 35 | **据置**（必殺の厚みを維持） |

## 非目標

- BT／RG 回復スキルの横展開
- 治癒の単体選定ルール変更
