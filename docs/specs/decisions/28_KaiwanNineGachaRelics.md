# 灰冠の九 — 装備ガチャ限定武具の世界観（P3-GACHA-EQ-KAIWAN-001）

**Status:** SSOT（Decision 承認済）  
**Approved:** 2026-07-31（オーナー GO — 組織名「灰冠の九」採用）  
**Scope:** 世界観・入手方針のみ。品目・数値・UI 実装は後続 Task。

---

## 1. 概要

装備ガチャ（招き画面の封蔵タブ想定）から出る **限定武具** は、歴史上の精鋭略奪組織 **灰冠の九（かいかんのく）** が奪い・使った品である。

正義の王遺産そのものではなく、**盗まれた写し・戦時特注・星炉の失敗作・封じ武具** を灰冠が私兵化した、という建前とする。

---

## 2. 確定

| # | 項目 | 決定 |
|---|---|---|
| 1 | 組織名 | **灰冠の九**（かいかんのく） |
| 2 | 時代 | 九王戦争〜静寂期に跋扈したと伝わる（実在の確証は諸説） |
| 3 | 性格 | 精鋭略奪団。建前は「王の遺産を守る」、実態は王墓・星炉・図書院などからの略奪と私兵化 |
| 4 | 象徴 | 歪んだ／欠けた **王冠紋の模刻**（炉印の偽物・逆さ・欠け）。「灰」は灰狼との語感接続と、栄華の灰 |
| 5 | 現行勢力との関係 | **灰狼団** は末裔・模倣・名乗りの盗用、のいずれかとして噂される（断定しない） |
| 6 | ガチャ限定武具 | **灰冠が盗んだ／用いた武具**のみ。通常ドロップ・鍛冶生産・降臨セット・深層専売とは別枠 |
| 7 | 出さないもの | 九対の王遺産・神話武器の実物、第十王遺産／王冠、降臨セット部位 |
| 8 | レア帯（方針） | 限定枠は E〜L。神話未満 |
| 9 | 効果トーン | 「悪い武器」— 代償付き・闇／呪い／破約／削って盛る等を優先（数値は後続） |
| 10 | 現在の流通 | ギルド回収部が押収・封蔵した匣を、魔晶石手続きで開封する（UI 名は後続。仮称「封蔵の匣」） |
| 11 | 灰狼団 | 現行の無法盗掘団として据置。格上げして灰冠そのものにはしない |

## 3. 公開フレーバー（コピー指針）

- 「盗まれた炉の武具。正義の刃ではない。」
