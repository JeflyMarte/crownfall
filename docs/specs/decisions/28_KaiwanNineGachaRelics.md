# 灰冠の九 — 装備ガチャ限定武具（P3-GACHA-EQ-KAIWAN-001）

**Status:** SSOT（Decision 承認済）  
**Approved:** 2026-07-31（組織）／002（武器9）／003（防具・装飾18）／004（限定ランダムステ）  
**Scope:** 世界観・限定武／防／飾の品目とメリデメ・灰冠専用ランダムステ方針。ガチャ UI／実装数値の最終調整は後続。

---

## 1. 概要

装備ガチャ（招き画面の封蔵タブ想定）から出る **限定装備** は、歴史上の精鋭略奪組織 **灰冠の九（かいかんのく）** が奪い・使った品である。

正義の王遺産そのものではなく、**盗まれた写し・戦時特注・星炉の失敗作・封じ武具** を灰冠が私兵化した、という建前とする。

---

## 2. 組織・入手方針

| # | 項目 | 決定 |
|---|---|---|
| 1 | 組織名 | **灰冠の九**（かいかんのく） |
| 2 | 時代 | 九王戦争〜静寂期に跋扈したと伝わる（実在の確証は諸説） |
| 3 | 性格 | 精鋭略奪団。建前は「王の遺産を守る」、実態は王墓・星炉・図書院などからの略奪と私兵化 |
| 4 | 象徴 | 歪んだ／欠けた **王冠紋の模刻**（炉印の偽物・逆さ・欠け）。「灰」は灰狼との語感接続と、栄華の灰 |
| 5 | 現行勢力との関係 | **灰狼団** は末裔・模倣・名乗りの盗用、のいずれかとして噂される（断定しない） |
| 6 | ガチャ限定装備 | **灰冠が盗んだ／用いた武・防・飾**。通常ドロップ・鍛冶生産・降臨セット・深層専売とは別枠 |
| 7 | 出さないもの | 九対の王遺産・神話武器の実物、第十王遺産／王冠、降臨セット部位 |
| 8 | レア帯（方針） | 灰冠限定は **L（封蔵限定）**。神話未満 |
| 9 | 効果トーン | メリットとデメリットを **はっきり対で出す**（悪い装備） |
| 10 | 現在の流通 | ギルド回収部が押収・封蔵した匣を、魔晶石手続きで開封する（UI 名は後続。仮称「封蔵の匣」） |
| 11 | 灰狼団 | 現行の無法盗掘団として据置。格上げして灰冠そのものにはしない |
| 12 | 命名規則 | **二つ名（漢字）＋カタカナ固有名**（例: 灯断ノクス）。部位はアイコン／副題 |
| 13 | 席タグ | 九席（塞図／売境／裂鍵／違約／灯断／偽星／奪潮／枯翠／断継）。武・防・飾で共有 |
| 14 | 部位役割 | **防具**＝デメリットの変換／ビルドの守り側。**装飾**＝メリット増幅・3部位完成 |

### 5.1 3部位完成例（灯断）

- 武器 **灯断ノクス**（後列火力／開幕HP-8%）
- 防具 **灯断ダスクメイル**（ロス半減／前列弱）
- 装飾 **灯断ノクターン**（ロス分を初撃へ／回復減）
- → 後列で開幕に削り、その分を初撃にぶつけるビルド

### 5.2 フレーバー

- 塞図クロスリット: 「地図の余白を切り捨てる剣。最初の一太刀だけが道を塞ぐ。」
- 灯断ノクス: 「街道の灯を奪った矢。道標はもう指せない。」
- 共通: 「盗まれた炉の武具。正義の刃ではない。」／欠け王冠紋の模刻

中核の謎（王冠＝第十、継承の真相）には踏み込まない。
