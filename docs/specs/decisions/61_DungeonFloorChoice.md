# ダンジョン分かれ道（次フロア三択）（P3-DG-FLOOR-CHOICE-001）

**Status:** Decision 承認済（2026-08-03 — オーナー GO）  
**Impl:** `P3-DG-FLOOR-CHOICE-001`  
**関連:** P3-D053（旧分岐撤廃）／碑文 `floor_blessing_*`／フルオート進行

---

## 1. 方針

旧「安全／危険／不明」分岐ではなく、**戦闘勝利後の短期ブースト選択**として復活する。  
自動進行は選択中のみ停止し、確定後に再開する。

| # | 項目 | 確定 |
|---|---|---|
| 1 | タイミング | 戦闘クリア後は通常どおり自動進行→暗転し、**階層キャプション（例: `[宝箱] F2`）の代わりに三択**。ボス直前・最終F・次が非戦闘は出さない |
| 2 | 頻度 | 章あたり最大2回（`floor_count`≤6 は最大1回） |
| 3 | 寿命 | **次の1フロアのみ** |
| 4 | UI | `UI_DG_FloorChoice_BG`（Downloads「３択背景」）。説明文は3パネルのアイコン下四角に配置。確定は絵のボタン位置 |
| 5 | A 戦力 | 与ダメ **×1.5**（次F） |
| 6 | A′ 応急 | 平均HP&lt;60% または戦闘不能1人以上のときのみ A を差し替え。次F開始時に生存者 **最大HP25%回復** |
| 7 | B 収穫 | EXP／Gold／素材／装備から **ランダム2種を提示**（×1.35）。プレイヤーは種目を選ばない |
| 8 | C 強襲 | 次Fを **ELITE＋護衛1〜2** に確定。報酬4種すべて **×1.25** |
