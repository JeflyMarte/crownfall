**Status:** SSOT（Decision 承認済）

## 概要

プレイヤーが育てたキャラを「一枚の自慢構図」で見せる画面。Phase1 はオフラインのみ。

## Phase1 要件

| 項目 | 内容 |
|---|---|
| 構図 | 左=装備／中央=Idle／右=実効ステ。**総合戦力＝名前直上**、**キャラ変更＝装備とステのあいだ** |
| 自枠 | `GameState.showcase_member_id`（roster の安定 id）最大1 |
| スタッフ | ローカルプリセット（セーブ非汚染）。**β理想ビルド5枠**（レジェンド以下・エンシェント／ミシック不可・深層なし） |
| スタッフ名札 | `{キャラ名}({ビルド名})` 例: `アルド(出血主砲ビルド)` |
| 導線 | 下ナビ「展示室」（マイページは下ナビからオミット。拠点左メニュー等から到達可） |
| BGM | hub |
| 総合戦力 | **P3-UI-COMBAT-POWER-001**（`docs/specs/decisions/22_CombatPower.md`） |
