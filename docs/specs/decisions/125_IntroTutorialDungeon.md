# 導入バトルチュートリアル 0-0（P3-INTRO-TUTORIAL-001）

**Status:** Decision 承認済（2026-08-18 オーナー GO・案A・スキップなし）  
**上書き:** `02_NewGameIntro.md` の「強制ダンジョン突入はしない／戦闘チュートリアル戦闘はスコープ外」。操作ハイライトツアーは引き続き採用しない。

---

## 1. 方針

リリース後の「バトルが分からない」への最短対処。導入の途中で **短い強制ラン** を1回だけ挟み、自動戦闘・画面の見方・宝箱・分かれ道だけを教える。

- スキップなし（撤退も出さない）
- 既存セーブの続きからは出さない（`intro_tutorial_pending` が立っている新規のみ）
- ダンジョン一覧に出さない・再プレイなし
- 1-1 の進行・調査・装備ドロップ・魔晶石には使わない

---

## 2. フロー

```text
Title「はじめから」
  → 世界観スクロール → 隊長名 → ニーナ（吹き出し3）
  → 初期隊員1人選択
  → 【0-0 訓練坑・強制】
  → 拠点はじめガイド → ジャック支給
```

0-0 は選んだ1人のみ（ジャック未支給）。アプリ切断時は `intro_tutorial_pending` が残っていれば続きからまた 0-0 へ（部屋進行はセーブしない＝最初から）。

---

## 3. 0-0 構成

| 項目 | 値 |
|---|---|
| 表示 | **0-0 訓練用模擬水路**（モーンゲート地下水路の絵を流用） |
| `dungeon_id` | `intro_training`（`route_type=tutorial`・選択不可） |
| `stage_id` | `intro_0_0` |
| 部屋 | 戦闘 → 宝箱 → 三択（既存オーバーレイ） → 戦闘 |
| 敵 | 固定1体・弱い・逃げない・群れなし（セピアハウンド／ルーンローチの見た目＋訓練ステ） |
| 宝箱 | 少量ゴールドのみ（装備なし） |
| 結果画面 | 出さない。ニーナ「訓練は以上」→ 拠点 |
| 天候・放浪・罠 | なし（探索罠・宝箱失敗ペナルティも出さない） |

説明はニーナの短いポップ（タップで次へ）。画面を指さす強制ツアーはしない。教えるのは自動戦闘／HPの見方／宝箱／三択のみ。三択は本編どおり、無操作なら 10 秒後に左が自動確定する。

---

## 4. 導入理由（ニーナ）

隊長登録は通った。現場の感覚は言葉では伝わらないので、隊員を1人選んだらギルド地下の訓練坑へ一度潜る。敵は弱く逃げない。戻ったら本調査の備えとジャックを付ける。
