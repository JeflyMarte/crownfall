# 指揮官 許可強化（パラゴン型）

**Status:** Decision 承認済（2026-08-02 — オーナー GO）  
**Impl:** `P3-CMD-PERMIT-BOOST-001`  
**関連:** `57_CommanderSPlusRanks`／`CommanderProfile`／マイページ

---

## 1. 方針

S+n 到達ごとに **許可点** を1点付与し、マイページから **許可強化** 画面で割り振る。Diablo パラゴンの薄い永続メタ成長。Board 分岐は持たない。

| 原則 | 内容 |
|---|---|
| 付与 | S+1 以降、到達段ごとに **+1**（累積・未使用可） |
| 系統 | **略奪／成長／戦力** の3行 |
| 再配分 | **いつでも無料**（スライダーで戻せる） |
| 既存S+ | 到達済み段数ぶんを一括付与（未割り振り） |
| 手当 | Gold／石／称号は据置（点とは別） |

---

## 2. 効果（薄め）

1点あたり **+2%**（戦力の防御は flat）。

| 系統 | 効果 |
|---|---|
| 略奪 | Gold 獲得＋／素材ドロップ率＋・個数＋（装備レア重量は対象外） |
| 成長 | 戦闘 EXP ＋ |
| 戦力 | パーティ HP％＋／防御 flat（`points × 2`） |

系統ごとの硬上限は設けない（点が S+ ペースでしか増えない）。

---

## 3. UI

- マイページ: **最近のハイライトをオミット** → **許可強化** 遷移ボタン（未使用点バッジ）
- 許可強化: 縦3行（略奪／成長／戦力）。設定の音量と同型の **HSlider** で増減
- ランクアップ祝辞: S+ 到達時に「許可点 +N」を併記可

---

## 4. セーブ

`GameState.commander` 配下:

- `permit_points_earned: int`
- `permit_alloc: { plunder, growth, power }`（各 int）
