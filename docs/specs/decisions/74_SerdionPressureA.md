# Decision: セルディオン火力強化（案A）

**ID:** P3-BAL-SERDION-A-001  
**日付:** 2026-08-05  
**状態:** 承認（オーナー GO・案A）

## 要旨

①ボス・セルディオンは全ストーリーボス中 ATK が最低（120）で、常時火力が薄く感じられた。  
基礎 ATK と薄い常時技（爪・咆哮）を上げ、断罪・威圧・薙ぎは据置。

## 決定

| # | 内容 |
|---|---|
| 1 | `serdion.attack` **120→145** |
| 2 | `enemy_serdion_claw` **×1.5→1.7** |
| 3 | `enemy_serdion_roar` **×0.5→0.75** |
| 4 | 薙ぎ×1.0／断罪×2.0／威圧×0.25／激昂・フェーズ閾値は据置 |

## 非目標

- 他ボス一括の ATK／即時全体倍率の横展開
- 断罪の CD・詠唱変更
- HP・DEF 変更
