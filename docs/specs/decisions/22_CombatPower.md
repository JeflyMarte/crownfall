# 総合戦力（P3-UI-COMBAT-POWER-001）

**Status:** Decision 承認済（2026-07-28 オーナー GO）  
**上書き:** 旧式 `HP+ATK+DEF` 単純合計

---

## 1. 方針

表示・調査速度比例・編成ヘッダで使う **総合戦力** を、戦闘でプラスに効くステをすべて反映した式に統一する。

経済バフ（Gold／EXP／ドロップ）・属性・スキル／必殺／状態付与率は含めない。

---

## 2. 確定

| # | 項目 | 決定 |
|---|---|---|
| 1 | 式 | `HP + 防御 + 攻撃 × 速度 × (1 + 会心率 × (会心ダメ − 1))`（四捨五入で整数） |
| 2 | 入力 | `RosterUiHelper.compute_member_stats` の実効値（装備・強化・Affix・職・Lv 込み） |
| 3 | 会心率 | 0〜1 にクランプ |
| 4 | 速度／会心ダメ | 負にしない（速度≥0、会心ダメ≥1） |
| 5 | パーティ総合 | メンバー各人の総合戦力の合計 |
| 6 | 適用先 | 編成ヘッダ／調査速度比例元／**展示室ステ最上段** |
| 7 | 除外 | スキル・パッシブ・属性・経済 Affix・付与率 |

---

## 3. 表示（展示室）

- 右ステパネル最上段に「総合戦力」＋数値
- その下に従来どおり HP／攻／防／速／会心／会心ダメ

---

## 4. 実装メモ

- SSOT: `RosterUiHelper.compute_member_combat_power` / `combat_power_from_stats`
- `SurveySystem.investigator_combat_power` は上記を呼ぶ
- ダンジョン「推奨戦力」式は据置（比較用目安。必要なら後続で再キャリブ）
