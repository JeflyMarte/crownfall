# Decision: 全ボス火力を案A同型へ横展開

**ID:** P3-BAL-BOSS-PRESSURE-A-001  
**日付:** 2026-08-05  
**状態:** 承認（オーナー指示・セルディオン案Aに合わせて他ボスも修正）

## 要旨

セルディオン案A（ATK・単体通常・即時全体）を、ストーリーボス13体へ同型で揃える。  
梯子の相対差は **旧ATK×(145/120)** で維持する。

## 決定

| # | 内容 |
|---|---|
| 1 | 全ボス単体通常（`basic`・`party`）**×1.5→1.7** |
| 2 | 全ボス即時全体（圧力AoE）**×0.5→0.75** |
| 3 | セルディオン以外の ATK を **旧値×145/120**（四捨五入） |
| 4 | 薙ぎ×1.0／大技×2.0／Hex×0.25／フェーズ閾値は据置 |
| 5 | ビッグコズミックダック・エリートは対象外 |
