# Decision: T6/T7 通りにくさ＝減衰後表示＋HP減＋ヒットごとパッシブ

**ID:** P3-BAL-TRICKY-RESIST-A-001  
**日付:** 2026-08-05  
**状態:** 承認（オーナー GO・推奨案A＋P2）

## 要旨

T6/T7（通常 or スキル被ダメ×0.2）は数字が減衰前のままで学習しづらく、HPも厚く粘りすぎた。  
**減衰後ダメージをテロップに合わせ**、HPを下げ、軽減が効いた攻撃のたびに短いパッシブ名を出す。

## 決定

| # | 内容 |
|---|---|
| 1 | 与ダメ頭上数字＝**T6/T7 減衰後**（実HP減と同値） |
| 2 | 軽減が効いた攻撃のたび `◇ 硬殻`（T6）／`◇ 幻障`（T7）を表示（P2） |
| 3 | T6/T7 の HP を概ね **×0.65**（ミストマンティスのみ ×0.80） |
| 4 | 軽減倍率 **×0.2** 自体は据置 |
| 5 | 旧「戦闘内初回のみ」長文テロップはヒットごとパッシブ名に置換 |
