# Biome深層（無限エンド）（P3-DG-ABYSS-001）

**Status:** SSOT（Decision 承認済）  
**Approved:** 2026-07-25  
**Impl:** 未着手（β後アップデート枠）

## 概要

メイン5 Biome（モーンゲート〜フロストリッジ）各1本の **深層ダンジョン**。  
エンドコンテンツとして **1Fから段階強化**し、**99F以降も無限に延長**する。  
報酬の本命は **深層限定レジェンド装備**。

寄り道（短編整備）・征討（伝説個体Boss）とは **別枠**。

## 確定ルール

| # | 決定 | 内容 |
|---|---|---|
| 1 | 枠 | `kind=abyss`（仮）。Biome×5本。寄り道／征討と ID 空間を分ける |
| 2 | 解放 | 当該 Biome **ノーマル Boss クリア後** |
| 3 | 難度帯 | 1–32 ≈ Normal／33–65 ≈ Hard／66–99 ≈ Nightmare／100+ は NM 超えの緩やかな上積み |
| 4 | マイルストーン | **33／66／99** に確定報酬（初回厚・2回目以降薄） |
| 5 | 本命報酬 | Biomeごと **深層限定レジェンド武器** 1本（計5）。初回99で確定。以降は低確率＋ソフト天井。詳細は **P3-DG-ABYSS-LEG-001** |
| 6 | 無限 | 99で終了せず継続。**最高到達Fをセーブ**。途中退出可 |
| 7 | 周回経済 | Gold／通常装備／素材は減衰。深層レジェンドは量産禁止（天井付き低確率） |
| 8 | 進捗UX | 途中退出で進捗保持。可能なら 10F チャンク表示（Impl詳細） |

## マイルストーン報酬（初稿・数値は Impl 前に調整可）

| 到達 | 初回 | 2回目以降 |
|---|---|---|
| **33F** | 当該 Biome 高品質素材一式＋魔晶石 | 素材のみ（控えめ） |
| **66F** | ★3確定枠（チケット or 直ドロップ）＋希少素材 | 素材＋少量魔晶石 |
| **99F** | **当該 Biome 深層限定レジェンド確定**＋称号／実績フック | 天井材料 or 低確率再抽選材料 |
| **100F〜** | 深層限定の再ドロップ／強化素材（確率制）。10Fごとに番人級で天井進捗 | 減衰維持 |

## 100F以降

- 敵ステは NM 基準から **緩い逓増**（線形爆発禁止）
- **10Fごと**に番人級 Elite／Mini。深層レジェンド天井進捗を付与
- 初版は Biome 敵・背景流用＋階数帯の修飾子差分でよい

## 非要件（本 Decision 外）

- オンラインランキング／他プレイヤー比較
- メタ恒久バフ（メインドロップ恒久＋％等）
- 深層レジェンドの基礎数値・スキルID詳細（**P3-DG-ABYSS-LEG-001** で名前／効果方向は確定。数値は Impl）
- β期間中のプレイ解放（`SUB_DUNGEONS` とは独立フラグで制御予定）
