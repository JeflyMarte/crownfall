## 1. 方針

本編は **群れ頻度と NM エリート複数**で圧を足す。ボス編成強化は **無限の 33F 周期**に寄せ、本編ボスの読み合いを壊さない。

| 領域 | 確定 |
|---|---|
| 本編 COMBAT | 群れ率 H×1.35／NM×1.75（上限は既存 0.95） |
| 本編 ELITE | N/H=護衛1〜2据置。NM=双エリート薄護衛 **または** 単＋護衛2〜3 |
| 本編 BOSS | **単体据置** |
| 無限 BOSS | 33/66/99/132…で編成パック（下表） |
| 報酬 | **据置** |
| 上限 | `SWARM_SIZE_CAP=5` 厳守。人数連動は ELITE/BOSS 適用外のまま |
