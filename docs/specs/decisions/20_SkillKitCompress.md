**Overrides:** P3-SKILL-002〜006 の「職あたり習得10」／同型単体スキルの量産方針

- 装備1枠でも「この職は何をするか」が分かる

- 群れ戦向けに **敵全体ダメ／敵全体状態／味方全体バフ** を正式に足す

## 4. 圧縮で外すもの（方針）

- 同系統の「単体ダメ＋同じ状態」の中間帯（疾風／猛撃／強射／クイック等の差が薄いもの）
- 職をまたいだ重複（例: 両職の標的射・甲砕の多重掲載）は **1職の代表1本** に寄せる
- 外した SkillData は削除必須ではない（図鑑・テスト・武器参照が残る場合あり）
