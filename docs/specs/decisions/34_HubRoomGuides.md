# 拠点部屋ガイド（調査室／招き／封蔵／展示室）

**Status:** Decision 承認済（2026-08-02 オーナー GO・推奨案一式）  
**Impl:** 同日  
**関連:** `21_DungeonRouteGuides.md`（同一書籍オーバーレイ）／`28_KaiwanNineGachaRelics.md`（封蔵文面）

---

## 1. 方針

拠点の主要部屋で、初回入室時に記録官ニーナの書籍手引きを出す。  
UI はダンジョン枠ガイドと同系統（`DungeonRouteGuideOverlay`）。

| ガイド | 見出し | 自動初回 | 再表示 |
|---|---|---|---|
| 調査室 | 調査室とは | 初回入室 | ヘッダ「？」 |
| 招待状（招き） | 招待状とは | 招きページ初回 | ヘッダ「？」 |
| 封蔵 | 封蔵とは | 封蔵ページ初回 | ヘッダ「？」（ページ連動） |
| 展示室 | 展示室とは | 初回入室 | 右上「？」 |

招きと封蔵は **別フラグ・別ガイド**（ページ切替でそれぞれの初回を出す）。

---

## 2. 文面必須要素

| ガイド | 必須 |
|---|---|
| 調査室 | 資料調査＋**派遣完了時のキャラ EXP／育成** |
| 招待状 | 魔晶石で仲間を迎える／封蔵への導線 |
| 封蔵 | 世界観上の「封印を解く武庫」＋**灰冠の九**（略奪団・限定装備・メリデメ） |
| 展示室 | 総合戦力の見せ場／スタッフ作例 |

---

## 3. フラグ

`GameState.tutorial_flags`:

| キー | 意味 |
|---|---|
| `hub_guide_survey_seen` | 調査室ガイドを初回で閉じた |
| `hub_guide_gacha_invite_seen` | 招待状ガイドを初回で閉じた |
| `hub_guide_gacha_seal_seen` | 封蔵ガイドを初回で閉じた |
| `hub_guide_showcase_seen` | 展示室ガイドを初回で閉じた |

ボタン再表示は preview（seen フラグ非接触）。

---

## 4. スコープ外

- 鍛冶屋・図鑑・日課など他部屋の初回ガイド
- 強制操作ロック
- 灰冠個別装備の詳細解説（図鑑／手引き SYS 側）
