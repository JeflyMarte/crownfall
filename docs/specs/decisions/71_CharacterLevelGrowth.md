# Decision: キャラ別レベル成長（H1）

**ID:** P3-BAL-GROWTH-H1-001  
**日付:** 2026-08-04  
**状態:** 承認（オーナー GO）

## 要旨

レベル成長を **HP / ATK / DEF** の三ステに拡張し、現行ロスター（スターター5＋ガチャプール11）に **キャラ別成長倍率** を付ける。高火力は ATK が伸びやすく DEF が控えめ、タンクは逆、など。

## 決定

| # | 内容 |
|---|---|
| 1 | 基礎伸び（倍率1.0）: Lv1〜50 は HP+48 / ATK+16 / **DEF+8**、Lv51〜99 は半減（HP+24 / ATK+8 / **DEF+4**） |
| 2 | 倍率 SSOT: `scripts/roster/CharacterGrowthRates.gd` |
| 3 | 適用: `LevelSystem.level_*_bonus(level, member)` → 戦闘 HP／与ダメ／被ダメDEF／編成UI |
| 4 | 未定義 id（ペット等）は倍率 1.0 |
| 5 | プール外 `_omitted` は当面デフォルト（必要なら後日） |
| 6 | **C′（追記）** — 味方DEF成長の被ダメ減を、敵レベル連動ATK（`ENEMY_LEVEL_ATK_K` **0.10→0.13**）で相殺。HP連動は据置 |
