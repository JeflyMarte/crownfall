# 敵バフ剥がし（P3-BAL-ENEMY-DISPEL-001）

**日付:** 2026-08-09  
**状態:** 承認（オーナー＝ボス／エリート／雑魚の一部に搭載）

## 要旨

味方の防御・鼓舞など強化が張り付く対策の第二段。パッシブ側の uptime 制限に加え、**一部の敵が有益バフを剥がす**。

## 決定

| ID | 決定 | 理由 |
|---|---|---|
| P3-BAL-ENEMY-DISPEL-001-1 | **`effect_type=dispel`**。対象の有益バフ（guard／empower／regen 系）を除去。氷殻も落とす | 新系統 |
| P3-BAL-ENEMY-DISPEL-001-2 | **毒・沈黙等デバフは残す** | 解呪＝強化剥がしのみ |
| P3-BAL-ENEMY-DISPEL-001-3 | **バフが誰にも無いときは不発**（CD消費しない） | 空振り防止 |
| P3-BAL-ENEMY-DISPEL-001-4 | **搭載** — 雑魚: 骨拾い／ヴェルガロン。エリート: グレイオス／クロックモス／夜沼。ボス: セルディオン／モルドガル／ネレイオン | 章をまたぐ一部 |

## 非スコープ

- 全敵への横展開
- 常時軽減パッシブ（ヴァルデン等）の無効化
- 味方側のディスペルスキル追加
