# 敵与ダメ圧力＋回復封じ／後列（P3-BAL-ENEMY-PRESSURE-001）

## 要旨

2-1 以降、とくに4人編成で回復が回るようになってから敵の殴りが痛くない。敵HPは据置し、**与ダメ・敵→味方 DoT・役割技**で圧力を戻す。

| ID | 決定 | 理由 |
