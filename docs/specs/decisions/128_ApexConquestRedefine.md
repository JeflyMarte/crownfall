## 3.1. 雰囲気・敵編成（案B・オーナー GO 待ち）

> **案A（フロスト雪山寄せ）は却下**（2026-08-27 — オーナー「雪山はすでにあるので別案」「敵はダンジョン問わずバラバラでよい」）。

### 雰囲気（推奨・案B）

| 項目 | 内容 |
|---|---|
| 一言 | **地図が裂け、Biome が混ざる余白。道標は嘘になり、見知らぬ生態が隣り合う** |
| ビジュアル | **本編5 Biome の既存戦闘背景を数Fごとに切替**（新規アート不要）。`north_reach`＝フロスト固定はやめる |
| 切替目安 | 1–4 モーン／5–8 ウィスパー／9–12 ミストフェン／13–16 ブラックショア／17–19 フロスト／20 Boss |
| 天候 | **吹雪固定にしない**。無し〜霧寄り、または帯の親 Biome を薄く踏襲 |
| 有利属性 | **帯ごとに親 Biome の favored を継承**。Boss 階のみ炎有利（アルバーク） |
| 放浪 | **無効** |
| flavor 案 | 境界標の先で地図が破れた。森の獣が潮の横を歩き、坑道の影が雪原に落ちる。名を呼べば呼ぶほど、余白が広がる。 |
