## 3.1. 雰囲気・敵編成（案C・**承認済**）

> **案A（雪山）・案B（Biome混成／地図破れ）は却下**  
> 2026-08-28 — オーナー「高い塔・空がテーマ」／**2026-08-30 オーナー GO**

### ステージは何か

| | 内容 |
|---|---|
| タイプ | **高塔ダンジョン**（遺跡短編でも Biome 混成でもない） |
| 正体 | 北辺境・最果てに立つ **天望の塔** — 開拓時代の境界標／見張り塔を後世が「地図の先まで登る」調査塔として使う |
| 征討名との関係 | **地図なき主**＝塔頂の主（アルバーク）。プレイは **塔を登る** 一本 |
| ロア接続 | フロストリッジの「境界標が北を指す」／ノースリーチ＝地図余白。塔頂だけが **載らない空** |

### 雰囲気（案C）

| 項目 | 内容 |
|---|---|
| 一言 | **石の塔を登り、上層ほど空と風が近づく。最上階だけ白闇の余白** |
| ビジュアル | **単一系統**。下〜中層＝`valgard_boundary` 背景（砦壁・回廊）。上層〜頂＝同系統 or フロスト Late 等 **空が開ける** 既存BG。Biome 切替なし |
| 天候 | **風・薄雲**（吹雪・地下感は出さない）→ 実装正は **`133` W-A**（晴れ55／霧25／雨10／夜10／吹雪0・run固定） |
| 有利属性 | **雷 or 聖**（高所・砦跡系。Impl 時 `valgard_boundary` 準拠で **holy** 可）。Boss 階は **炎**（アルバーク） |
| 放浪 | **無効** |
| flavor 案 | 最果ての天望塔。階を上げるほど街の灯は遠のき、云だけが近い。地図に載らない最上階に、白甲の主がいる。 |

| 帯 | F | 感覚 |
|---|---|---|
| 塔門〜下層 | 1〜7 | 石回廊・番人獣。登り始め |
| 吹き抜け | 8〜14 | 強風・鳥影。空が見える |
| 雲上 | 15〜19 | 竜種・翼。地名が消える |
| 塔頂 | 20 | アルバーク（地図なき主） |

### 敵（案C・既存のみ・**塔／高所／空**に寄せる）

新規なし。**ダンジョン横断のランダム混成はしない**（世界の塔に棲む／通過する既存種のみ）。

| 帯 | 雑魚（例） | Elite（例） |
|---|---|---|
| 下層 | `rock_bison`（岩角・砦壁）, `iron_horn`, `moss_shell` | `rock_bison` |
| 中層 | `crown_raven`, `grave_bell_bat`, `wind_ripper` | `mist_wyvern` |
| 上層 | `storm_joe`, `wind_ripper`, `greios`（稀） | `greios`, `mist_wyvern` |

**プール案（単一 pool・実装ピン）:**

| 枠 | id |
|---|---|
| `enemy_pool` | `rock_bison`, `iron_horn`, `moss_shell`, `crown_raven`, `grave_bell_bat`, `wind_ripper`, `storm_joe` |
| `elite_pool` | `greios`, `mist_wyvern`, `rock_bison` |
| Boss | `albark` |
| 出さない | 海／沼／坑道専用（`ship_eater_crab`, `sepia_hound` 等）／`eldion`／案B の Biome 混成セット |

> 敵 id は **塔・空・砦** に合う既存のみ。GO 後に `north_reach.tres` へ反映。  
> **希少感:** `crown_raven` / `rock_bison` は `spawn_weight_mult = 0.2`（等重みだと征討で過多。本編放浪率は別経路）。
