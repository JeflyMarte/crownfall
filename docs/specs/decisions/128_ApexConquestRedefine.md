## 3.1. 雰囲気・敵編成（案A・オーナー GO 待ち）

### 雰囲気

| 項目 | 内容 |
|---|---|
| 一言 | **道標も足跡も消える白闇の余白。名を呼べば呼ぶほど、地図からこぼれる** |
| ビジュアル／天候 | フロストリッジ系背景＋吹雪強め。視界が白く潰れる「余白」感 |
| 有利属性 | **炎**（親 Biome 据置。氷竜を氷弱点にしない） |
| 放浪 | **無効**（降臨に準拠。空白に迷い込む物語は雑魚／Eliteで足りる） |
| flavor 案 | 最果ての門の先、境界標が途切れる。雪は道を消し、呼称は風に呑まれる。白甲の主は地図に載ることを拒む。 |

フロア進行の物語感（実装はログ／部屋名任意）:

| 帯 | F | 雰囲気 |
|---|---|---|
| 余白の縁 | 1〜7 | 足跡が薄れ、斥候獣が群れで試す |
| 白闇 | 8〜14 | 吹雪と咆哮。道が一本に見えない |
| 地図なし | 15〜19 | 重獣・竜種の圧力。名を呼ぶな、という圧 |
| 主 | 20 | アルバーク |

### 敵（既存のみ・案A）

新規モンスターなし。フロスト帯の既存を **役割で再配置**。

| 役割 | id | 表示名 | 狙い |
|---|---|---|---|
| 斥候・手数 | `frost_claw_raptor` | 霜爪ラプター | 縁の試探。速さ |
| 消去・吹雪 | `wind_ripper` | スノーストーム | 「地図が消える」逃走／突風。余白の象徴 |
| 白闇の声 | `vergaron` | ヴェルガロン | 吹雪咆哮。恐怖・凍結の前奏 |
| 氷縁の暴力 | `storm_joe` | ストームジョー | 中盤の厚み・沈黙寄り |
| 古の踏破 | `oldrex` | オルドレクス | 地図を踏み潰す巨躯。回復持ちで長期戦 |
| 影の迷い人（レア枠） | `ice_tail_fox` | 氷尾フォックス | 群れの縁の横取り。余白に残る小さな生 |
| Elite・翼 | `greios` | グレイオス | 空から余白を裂く |
| Elite・蹂躙 | `glacier_warden` | 氷晶マンモス | 道そのものを潰す |
| Boss | `albark` | 白甲の古龍アルバーク | 20F |

**プール案（実装値）:**

| 枠 | 内容 |
|---|---|
| `enemy_pool` | `frost_claw_raptor`, `wind_ripper`, `vergaron`, `storm_joe`, `oldrex`, `ice_tail_fox`（`wind_ripper` を二重登録して出現を厚くしてよい） |
| `elite_pool` | `greios`, `glacier_warden`（中盤以降の Elite 頻度を降臨N寄せで厚く） |
| 出さない | `eldion`（本編Bossと役割分離）／`polar_tricera`（オミット維持）／影狩り等の他Biome希少種（霜の余白を濁さない） |

> フロア帯ごとの強制差し替えは **必須にしない**（現行システムが単一 pool のため）。帯は flavor／Elite 率／群れ圧で表現。帯別 pool が必要なら後続 Decision。
