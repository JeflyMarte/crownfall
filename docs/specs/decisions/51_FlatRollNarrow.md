# 平坦ランダムステ帯の圧縮（案C）

**Status:** Decision 承認済（2026-08-02 — オーナー「推奨案でgo」）  
**Impl:** `P3-EQ-FLAT-ROLL-NARROW-001`  
**関連:** `06_EquipmentDiabloStats.md`／P3-BAL-STAT-SCALE-001

---

## 1. 方針

攻撃／防御／HPアップの一様ロールが広すぎる（下限≈1・上限が大きい）ため、**上限×0.7・下限＝上限×0.55** に圧縮する。

対象外（据置）: 回復20〜40、武器の防御アップ8〜16、会心／速度など率系、属性値。

---

## 2. 数値

| 定数 | 値 |
|---|---|
| `FLAT_ROLL_CEILING_MULT` | 0.70（上限表に焼き込み） |
| `FLAT_ROLL_FLOOR_RATIO` | 0.55 |

### 上限表（焼き込み後・×STAT_SCALE=8）

| 部位 | 種 | C / R / E / L |
|---|---|---|
| 武器 | 攻撃アップ | 32 / 40 / 56 / 80 |
| 防具 | 防御アップ | 24 / 32 / 48 / 80 |
| 防具 | HPアップ | 48 / 64 / 104 / 144 |
| 装飾 | 攻撃／防御 | 16 / 32 / 48 / 64 |
| 装飾 | HP | 32 / 56 / 80 / 112 |

例: ★武器攻撃アップ表示帯 ≈ **44〜80**（旧 1〜112）。

---

## 3. 互換

- **既存所持はリロールしない**（mods に保存された min_v/max_v/value を維持）
- 新規ドロップ／新規生成のみ新帯

---

## 4. 実装箇所

- `BalanceConfig.FLAT_ROLL_*`
- `*StatResolver.*_ROLL_MAX`
- `EquipmentRandomMods._flat_roll_bounds`／平坦アップ抽選
