# 硬殻敵の圧力スキル（P3-BAL-HARD-SHELL-PRESSURE-001）

**日付:** 2026-08-09  
**状態:** 承認（オーナー＝硬殻の持久戦解消・全体／状態異常／詠唱特大）

## 要旨

単体バースト（髑髏砕き等）だけでは膠着が残る。硬殻タンクに **詠唱特大全体** または **毒前列** を足し、スキル使用率も上げて持久戦を崩す。
