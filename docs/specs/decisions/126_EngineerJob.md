## 0. 一言

**敵に仕掛け（印）を付け、敵が動くたびに反応させる機械職。**  
矢の即時拘束（RG）でも薬の即時付与（AL）でもなく、**条件付きの罠が主役**。

旧案の「設置→起爆で回収」は本線にしない。起爆は将来の薄いオプションに下げ、核は **反応罠（B案）**。

## 2. ビルドテーマ3（本 Decision の主確定候補）

他職と同じく **職あたりテーマ3・各テーマにキャラ1（目安）**。Decision 93 に追記する想定。

| テーマ | プレイヤーが組むビルド | 戦闘で起きること | 既存職との差 |
|---|---|---|---|
| **罠** | 仕掛けを早く・多く付ける | 敵行動で発火（ダメ／鈍化など）。印の回転が本体 | RG拘束＝矢が当たった瞬間。こちらは **付いたあと、敵が動いて発火** |
| **連動** | 味方の攻撃と噛み合わせる | 仕掛け済みの敵を味方が殴ると追加発火／追撃 | VGカウンター＝自分が被弾して返す。こちらは **味方の攻撃がトリガー** |
| **破砕** | 硬い敵・殻を剥がす | 発火時に防御低下・殻削り・被ダメ増の下地 | AL脆弱＝今すぐデバフ。こちらは **仕掛けが発火したときだけ削る** |

### 2.1 パッシブ方向（数値は未定・ラベルだけ）

| テーマ | パッシブラベル案 | 効果の方向（後で数値） |
|---|---|---|
| 罠 | 先制設置 など | 開幕に印1／設置系の回転 |
| 連動 | 共鳴発火 など | 味方攻撃時に仕掛け発火率・威力 |
| 破砕 | 穿機構 など | 発火時に破砕スタック／DEF低下 |

方針は Decision 93 と同じ（1キャラ1ラベル・平与ダメ%メイン禁止）。

### 2.2 なぜこの3つか

| 候補に上がりやすいが採用しないもの | 理由 |
|---|---|
| 起爆（旧テーマ） | B案の核ではない。反応罠を薄める |
| 機巧適性／探索適性 | RG「探索適性」と枠が被る。罠部屋軽減は罠テーマの薄い副効果に留められる |
| 回復・挑発・ペット | 他職本家 |
| 状態異常本家 | BTと被る。発火時の薄い chill 等は罠の手段であってテーマ名にしない |

## 3. 戦闘システムの骨格（スキル未定でも固定したいこと）

### 3.1 仕掛けトークン

| 項目 | 内容 |
|---|---|
| 実体 | 敵1体に紐づく印 |
| HP／撃破 | なし |
| 上限 | パーティ合計で少数（例: 3・数値は後定） |
| 重複 | 1敵1印（上書き） |
| 寿命 | 戦闘終了で消滅。発火回数 or 時間でも消える |

### 3.2 発火

| 優先 | 条件 | 備考 |
|---|---|---|
| 主 | その敵が行動した | 攻撃・スキル等 |
| 連動テーマ | 味方がその敵を攻撃した | 連動ビルドの核 |
| 任意・薄い | 時間経過 | 罠テーマの補助。置きっぱなし最強にしない |

発火効果の振り分け（後詰め）:

- **罠**寄り … ダメージ／行動阻害  
- **連動**寄り … 味方ヒット連動の追加発火  
- **破砕**寄り … 発火時の装甲削り  

### 3.3 AI 思想（概略）

1. 印のない敵がいる → 設置を優先  
2. 上限なら通常攻撃  
3. 連動／破砕寄りの装備スキルがあれば、印がある敵を優先して殴る／支援する  

観察で分かること: 敵足元の印 → 敵が動く（または味方が殴る）たびに反応。
