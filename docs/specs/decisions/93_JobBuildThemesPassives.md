## 1. パッシブの役割（本ゲーム）

| # | 方針 |
|---|---|
| 1 | パッシブは職スキルの代わりではなく、**キャラの個性ラベル（1本・短く説明できる）** |
| 2 | 職キット＝毎戦闘の本体。パッシブ＝編成時に選ぶ偏り |
| 3 | 毎戦大きく効く永久保険（例: クリア後全体高回復）や平与ダメ%メインは避ける |
| 4 | **1キャラ1テーマ**。BTの「毒＋ペット」のような二軸併記をやめる |
| 5 | 職スキルもテーマに合わせて見直し可（既存キットへの無理な当てはめはしない） |

## 2. 職ごとのビルドテーマ（各3・非重複）

| 職 | テーマ1 | テーマ2 | テーマ3 |
|---|---|---|---|
| ソードマン | 出血 | 一撃 | 会心 |
| レンジャー | 標的 | 拘束 | 探索適性 |
| ヴァンガード | 挑発 | 味方バフ | カウンター |
| アルケミスト | デバフ | 回復 | 属性 |
| ビーストテイマー | ペット強化 | 状態異常 | 吸血 |

### 切り分けメモ

- **ALデバフ**＝脆弱・呪印など数値を落とす／通しやすくする  
- **BT状態異常**＝毒・冷却など状態そのものを付ける  
- **RG探索適性**＝非戦闘スキル・長期ダンジョン耐性（罠・継戦・発見など）。戦闘外スキル追加してよい  
- **BT吸血**＝自己またはペット経由のライフスティール（ペット強化・異常付与とは分離）

## 4. パッシブ粗案（実装前・方向のみ）

数値は後続バランス。**id は原則維持**して中身差し替え。

| キャラ | 現行表示名（参考） | 粗案 |
|---|---|---|
| アルド | 王炎の覇気 | **維持** — 攻撃時出血付与 |
| 火鷹 | 血潮の代償 | **変更しない** |
| カイダ | 一閃の賭け | **維持寄り** — 戦闘初撃の威力上昇 |
| リーヴァ | 狙印の刻 | **維持** — 攻撃時標的付与 |
| シアン | 静寂の構え | **差し替え** — 攻撃時に冷却または鈍化（拘束）。後列回避＋標的は外す |
| イヴァル | 辺境の踏破 | **維持〜拡張** — 自身の探索ダメ無効＋パーティ罠軽減。非戦闘スキル枠は職キット側で別途 |
| ガレン | 聖盾の砦 | **維持寄り** — 被ダメ軽減＋ヘイト |
| ヴァルデン | 鉄誓の壁 | **維持寄り** — パーティ被ダメ軽減（味方バフテーマ）。自己ヒールなし |
| ボルグ | 門前の残像 | **差し替え** — 被弾時カウンター（または反撃）。開幕回避は廃止 |
| ウォール | 不屈の鼓動 | **維持寄り** — 戦闘中じわ回復＋ヘイト（挑発分岐） |
| レノール | 呪印の増幅 | **維持寄り** — デバフ／状態異常持ちへの与ダメ増 |
| セリン | 予備瓶 | **維持寄り** — 味方瀕死帯で単体中回復（戦闘中限定回） |
| エリアス | 野営の残り香 | **差し替え** — 属性与ダメ増、または攻撃／スキルで属性付帯（炎など）。クリア後全体回復は廃止 |
| ネリ | 水鳥の指揮 | **短縮** — ペットステ強化（＋任意で蘇生は薄く残して可）。説明をペットのみに |
| ミレイ | 毒牙の共鳴 | **差し替え** — 攻撃時毒付与のみ。ペット倍率削除 |
| ルーシェ | 獣呼びの絆 | **差し替え** — 吸血（与ダメの一部回復）。冷却付与・行動時ペット回復は削除 |
