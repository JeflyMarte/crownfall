# 氷晶マンモス：防御無視全体（P3-BAL-MAMMOTH-IGNORE-DEF-001）

**日付:** 2026-08-09  
**状態:** 承認（オーナー＝マンモスに防御無視の全体攻撃）

## 要旨

氷晶マンモスは硬殻＋通常耐性で持久戦になりやすい。**味方 DEF 逓減をスキップする詠唱全体**を追加し、タンクの装甲だけに頼った膠着を崩す。

## 決定

| ID | 決定 | 理由 |
|---|---|---|
| P3-BAL-MAMMOTH-IGNORE-DEF-001-1 | **`SkillData.ignore_defense`**（既定 false）。敵→味方で DEF 逓減のみスキップ。guard／属性耐性／block は残す | 装甲無視＝DEFのみ。他軽減は別系統 |
| P3-BAL-MAMMOTH-IGNORE-DEF-001-2 | **氷晶の蹂躙** — 詠唱1・全体×1.65・氷・冷却35%・CD12・`ignore_defense` | 通常全体より倍率を抑え、DEF無視でタンクにも刺す |
| P3-BAL-MAMMOTH-IGNORE-DEF-001-3 | 使用率0.36・核スキル重み優先。既存単体は残置 | 出番確保 |

> **上書き（2026-08-09）:** `116_FrostEliteMammoth` — マンモスはエリート化。蹂躙は ×1.40／CD14／冷却25%。

## 非スコープ

- 他敵への `ignore_defense` 横展開
- 味方スキル側の防御無視
