# プレスキット構成チェックリスト

Google Drive（または同等）にフォルダを作り、**リンクを知っている全員が閲覧可**にする。

推奨フォルダ名: `Crownfall_PressKit_2026`

## 必須

- [ ] `01_icon/` … App Icon（1024px 相当の高解像度）
- [ ] `02_screenshots/` … 縦スクショ 4〜8枚（戦闘／拠点／装備／ダンジョン選択など）
- [ ] `03_preview/` … App Store用プレビュー動画（正しい寸法の mov）
- [ ] `04_logo/` … ロゴがあれば（なければアイコンで可）
- [ ] `press_release.txt` または `.md` … 本リポジトリの `press_release.md` をコピー
- [ ] `README.txt` … タイトル、価格、ストアURL、連絡先を5行で

## あると強い

- [ ] `05_gif/` … 自動戦闘や拠点→出発の短いGIF（AUTOMATONのX投稿向け）
- [ ] `06_key_art/` … キービジュアル1枚
- [ ] 英語1段落（海外メディアは後回しで可）

## README.txt 例

```
Crownfall / クラウンフォール
自動探索ハクスラRPG（iOS）
価格: ¥500（買い切り）
App Store: https://apps.apple.com/jp/app/crownfall/id6800287771
Contact: {{CONTACT_EMAIL}}
```

## 完了後

1. Drive の共有URLをコピー
2. Cursor に「プレスキットURLはこれ: …」と渡す → 文面の `{{PRESS_KIT_URL}}` を一括置換
3. Priority A の送付開始
