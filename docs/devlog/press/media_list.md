## 送らない／後回しでよいもの

- 有料記事広告のみの枠（予算決定後）
- 完全にPC/Steam専用でスマホを扱わない媒体（判断が難しい場合は送ってよいが期待値低）

## 送付ルール

1. BCC一斉送信はしない
2. 件名は `email_template.md` の推奨件名を使う
3. プレスキットURLを必ず入れる
4. 送ったら `send_tracker.md` に記録
