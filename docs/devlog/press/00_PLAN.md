# Crownfall — ゲームメディア一斉PRプラン

最終更新: 2026-08-20

## ゴール

国内ゲーム／インディー寄りメディアへプレスリリースを一斉送付し、掲載・SNS拡散による App Store 流入を増やす。

## 自動化の境界

| 担当 | 内容 |
|---|---|
| **Cursor（自動）** | プラン、プレス本文、メール文面、送付先リスト、チェックリスト、進捗表の下書き |
| **オーナー（必須）** | Google Drive プレスキット公開、スクショ／動画配置、各フォーム／メールの送信、返信対応 |
| **できないこと** | オーナー名義での自動メール送信、掲載保証、有料記事広告の発注代行 |

## フェーズ

### Phase 0 — 店頭の最低整備（送付前・推奨）

送ったあとにストアが弱いと機会損失になる。可能なら先に直す。

- [ ] App Store 日本語 Name（例: クラウンフォール：自動探索ハクスラRPG）
- [ ] サブタイトル／キーワード整備
- [ ] プレビュー動画が正しい寸法で載っていること
- [ ] 著作権表記を仮会社名に合わせておく（任意）

### Phase 1 — 素材作成（Cursor 済／本フォルダ）

- [x] プレスリリース本文 → `press_release.md`
- [x] 送付メール文面 → `email_template.md`
- [x] 送付先リスト → `media_list.md`
- [x] プレスキット構成 → `press_kit_checklist.md`
- [x] 進捗表 → `send_tracker.md`

### Phase 2 — プレスキット公開（オーナー 15〜30分）

1. Google Drive にフォルダ作成（閲覧「リンクを知っている全員」）
2. `press_kit_checklist.md` のファイルを置く
3. 共有URLを `press_release.md` / `email_template.md` の `{{PRESS_KIT_URL}}` に差し替え

### Phase 3 — 送付（オーナー／媒体ごと・所要約60〜90分）

優先順（スマホ有料インディー向き）:

1. AUTOMATON（メール）
2. indiegamesjapan（メール）
3. gamebiz（メール）
4. Gamer（メール）
5. もぐらゲームス（フォーム）
6. Game*Spark（イードフォーム）
7. インサイド（イードフォーム）
8. 4Gamer（先に問い合わせ → アドレス受領後に送付）
9. ゲームドライブ（フォーム）
10. GIGAZINE（ニュースリリースフォーム）
11. 電ファミ／ファミ通／IGN など（余裕があれば）

ルール:

- 一斉 BCC は使わない（媒体ごとに個別）
- 件名は「何のゲームか」が分かる文言をそのまま使う
- 送付後は `send_tracker.md` に日付を書く

### Phase 4 — フォロー（送付後 3〜7日）

- 掲載されたら X／Note／Wiki にリンクを追記
- 未返信でも催促メールは基本しない（1通で十分）
- 掲載URLを `send_tracker.md` に記録

## 成功の見方（現実的）

| 指標 | 目安 |
|---|---|
| 送付完了 | 優先10媒体以上 |
| 掲載 | 1〜3媒体で十分成功 |
| ストア | 掲載日前後で初回DL・チャートの動きを Connect で確認 |

載らなくても失敗ではない。インディーの無料送付は通過率が低いのが普通。

## 次アクション（オーナー）

1. Drive にプレスキットを置く（`press_kit_checklist.md`）
2. `{{PRESS_KIT_URL}}` と連絡先を埋める
3. `media_list.md` の Priority A から順に送る
4. 送るたびに `send_tracker.md` を更新

Cursor に「Drive URL を差し替えて」「返信が来たので追記して」と言えば文面更新を続ける。
