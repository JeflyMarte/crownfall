# 【Crownfall】スマホ向けハクスラゲーム作成日記 ⑧【モンスター編】

前回は状態異常・スキル・連携・必殺の話をしました。今回は、それを受け止める側——モンスターです。

①でも少し書いたんですが、今作の敵は全員「生物」です。魔法で動く骸骨とか、闇から湧いた抽象モンスターはあまり置いていません。土地に適応した生き物がいる、という前提で組んでいます。テーマは「探索と生態系」です。

（画像: 図鑑のモンスター一覧、または戦闘中の敵スプライト）

#なぜ全員生物か

ハクスラって、敵は「経験値とドロップの袋」になりがちです。それ自体は否定しないんですが、僕は生き物が好きなので、倒したあとに「なんだったんだろう」と少し残る相手にしたかった、というのが本音です。

なので設計の軸はこうです。

- 実在の動物や昆虫を祖先にする
- 能力は魔法ではなく、その土地への適応として説明する
- エリアごとに適応の型を変える

たとえば王都地下（モーンゲート）は **鉱物化** です。遺物や結晶を体に取り込んだネズミ、ゴキブリ、ハリネズミ、蛾、みたいな感じです。森は苔や菌との共生、沼は腐敗の循環、海は潮汐、氷は寒冷——と、Biomeが変わると生態のルールも変わります。

ドット絵の世界でも「自然がある」と感じたかったので、背景や天候とセットで敵を置いています。

#敵の階層

戦闘で出会う相手は、だいたい次の層です。

**雑魚**  
いちばん多い。単体だと普通でも、群れになると急に危なくなります。自動進行だと「いつの間にか囲まれてた」が起きやすい層です。

**群れ**  
同じ種が複数出る部屋。序盤からあります。ハクスラの「雑魚掃討」感と、指揮官ゲームの「誰を先に落とすか」が同時に出るところです。

**エリート**  
見た目もキットも一段上。護衛の雑魚を連れてくることもあります。部屋に入った瞬間のテロップでも分かります。

**ボス**  
章の締め。フェーズや大技があって、必殺や連携の温存先になります。⑦で書いた必殺ゲージが溜まりにくいのも、だいたいこのへんです。

見た目の危険度は図鑑の星でも見られますが、体感としては「群れの密度」と「エリートの有無」で難易度が跳ねやすいです。

#トリッキーな個体

全部が同じ「単体ダメ＋状態」だと、編成を変える理由が薄くなります。なので、ところどころに役割持ちを置いています。全敵に一律ではなく、章に数体、という感覚です。

たとえばこんなタイプです。

- **回復役** — 敵側を治す。放置すると長い戦いになるので、優先キルしたくなる
- **味方バフ役** — 他の敵を盛り上げる旗持ち
- **全体に状態を撒く** — 低ダメージでもパーティ全体がしんどくなる
- **逃走** — 稀に逃げる。報酬なしなので、焦ると虚しい（希少種っぽい匂い）
- **自爆** — 最後に範囲で返す。倒したのに痛い
- **通常が通りにくい／スキルが通りにくい** — 突破手段が対になる。初見で「あれ？」となりやすい

戦闘中に一度だけ、軽減の説明テロップも出ます。⑦の状態異常とあわせて、「この敵は何屋か」を読むのが、指揮官側の仕事です。

甘いところ: 初見だと役割が分かりにくい個体もあります。図鑑やスキル説明で補っていますが、まだガイドは足りないです。

#希少種とイベント枠

メインの生態系とは別に、あちこちで出会う希少枠もあります。情報誌の「目撃増」や、曜日イベントとつながりやすい奴らです。

- **コズミックダック** — かわいいのに厄介、系の遍在種。専用のイベントダンジョンもあります
- **宝冠レイヴン** — 見た目からしてドロップ欲が出る鳥。伝説寄りの匂い
- **ゴールデンスカラベ** — 金が絡む逃走寄りの希少種
- **影狩り** — 強い。総取り感のある強敵枠
- **ロックバイソン** — 岩場寄りの群れ系。専用の日次イベントもあります

ここは「本編の生態」とは別の遊び（稼ぎ・運・曜日）用です。詳しいイベント回りはまた別の回に回します。今回は「図鑑を埋めたくなる枠がいる」くらいで十分です。

（画像: ダック or レイヴンの戦闘／イベントバナー）

#図鑑の楽しみ方

②でも図鑑には触れましたが、モンスター編なので少しだけ深掘りします。

倒すと段階的に情報が開いていきます。最初は名前と危険度くらいで、進むと弱点や調査記録が見えてきます。調査記録は、探索者が現場で書いたメモの口調にしてあります。強さの攻略文というより、「この土地でどう生きているか」の一行です。

キャラが強くなるわけではない、というのは②で書いたとおりです。ただ、弱点確認と「次どのBiomeの顔ぶれを覚えようか」には使えます。生物好きの自分へのサービスでもあります（はい）。

#エリアごとの顔ぶれ（チラ見せ）

全種類は並べません（多すぎます）。各エリアの匂いだけ。

**モーンゲート（王都地下）**  
鉱物化の入門帯。セピアハウンド、ルーンローチ、水晶ハリネズミ、冠喰いネズミあたりが顔役。エリートはクロックモス、ボスは水晶骸竜セルディオン。地下を降りるほど、年代が深くなる感じです。

**ウィスパーウッド（囁きの森）**  
苔と菌。モスボア、モスシェル、スポアウィドウ。硬い殻や回復役がいると、森らしく粘られます。ボスはフローラベア・グランヴェル。

**ミストフェン（霧沼）**  
腐敗と毒。吸血ヒル、ミストマンティス、沼地の王。回復や「スキルが通りにくい」個体も混ざるので、⑦の仕込みが試されます。ボスは底なしの王モルドガル。

**ブラックショア（沈没航路）**  
潮と甲殻。船喰らい、潮灯、ヴォイドテンタクル。標的や群れの印象が強い帯です。ボスは潮鳴王ネレイオン。

**フロストリッジ（最果て氷裂）**  
寒冷と大型。霜爪ラプター、ヴェルガロン、氷晶マンモス。逃げる猛禽や、通常が通りにくい巨体もいます。ボスは始祖の竜エルディオン。

（画像: 各Biomeの敵を1枚ずつ、または図鑑詳細）

#まとめ

モンスターは、ただの障害物ではなく「その土地の顔」として置いています。

おすすめの見方はこうです。

1. 雑魚／群れ／エリート／ボスのどれかを意識する
2. トリッキー個体がいたら、優先キルか突破手段を考える
3. 図鑑で弱点と調査記録を少し読む
4. Biomeが進んだら、適応の型（鉱物／共生／腐敗／潮／寒冷）の違いを楽しむ

アートはまだ直したい個体があります。仮絵や大きさのバランスが甘いところもあるので、そこは目を瞑ってください。方向性としては、「倒したあとに生態が残るハクスラ」を目指しています。

今回はモンスター編までです。次回は降臨ダンジョンか、助っ人キャラを残らず並べる回にしようと思います。
