# 【Crownfall】スマホ向けハクスラゲーム作成日記 ⑦【状態異常・スキル・連携・必殺編】

前回は無限ダンジョンの話をしました。エンドコンテンツの区切りや深層レジェンドはあれでだいたい掴めると思います。

今回はもう少し手前、戦闘の中身です。自動進行なのでプレイヤーはボタンを連打しないんですが、だからこそ「何を仕込むと噛み合うか」を事前に決める必要があります。状態異常・スキル・連携・必殺は、その仕込みの核です。

（画像: 戦闘中。頭上の状態アイコンと、下のスキル／必殺ゲージ）

#状態異常

まず状態異常です。毒や出血みたいな「じわじわ削るもの」、スタンや冷却みたいな「行動を止めるもの」、標的や呪いみたいな「ダメージを通しやすくするもの」があります。味方側には防御や鼓舞みたいなバフもあります。

ざっくり分けるとこんな感じです。

**削る系**
- 毒／出血／炎上 — 時間で削り続ける。長い戦い向き

**止める・遅くする系**
- スタン／冷却／鈍化／恐怖 — 敵のテンポを崩す。危ない技の前に刺さると気持ちいい

**弱らせる系**
- 標的／呪い／脆弱／防御DOWN／感電 — 後続のダメージが乗りやすくなる。単体では地味でも、積むと強い

**味方バフ**
- 防御／鼓舞 — 耐える／殴るを一時的に盛る

大事なのは、属性と状態異常は別物だという点です。炎属性の武器で殴っても、それだけでは炎上しません。弱点ダメージは乗るけど、炎上はスキルや敵の技など、別の経路で付きます（ここ、最初のうちは混同しやすいです）。

戦闘中はキャラや敵の頭上にアイコンが出ます。説明文の中の状態名をタップすると、短い効果ポップも出るようにしてあります。自動進行だとログが流れていくので、「今なにが乗ってるか」を画面で拾えるようにしたかった、というのが動機です。

甘いところもあります。種類が増えてきたので、初見だと全部覚えきれないです。手引きやポップで補完していますが、まだ「何を優先して積むべきか」のガイドは薄いです。

#スキル

スキルはジョブごとに覚えます。各職だいたい7本で、レベルが上がると解放されていきます（1／8／15／22／30／40／50あたりが節目）。

装備できるのは常に1本です。ゲージを見やすくしたかったのと、オート戦闘で「どの技を撃つか」を単純にしたかったからです。覚えている技は候補で、実際に持っていくのは1つ。ハクスラの装備枠と同じ感覚に近いです。

設計でこだわったのは、Lv1の技も終盤で捨てない、という点です。ただ威力だけ上がる同型スキルを並べると、覚えるほど古い技がゴミになります。なので短CDの回転技と、長CDの決め技を並べて、状況で選び替える形にしました。

職ごとの匂いだけ書くと、こんな感じです。

- **ソードマン** — 切れ味と出血。群れなら全体斬り、ボスなら出血を積んで追撃
- **レンジャー** — 標的と遠距離。硬い敵は剥がし、群れは斉射
- **ヴァンガード** — ヘイトと守り。味方全体に防御を張ったり、群れを軽く牽制
- **アルケミスト** — 回復と弱体。治癒の回転と、いざという大回復を使い分け
- **ビーストテイマー** — 毒とペット連携。群れに毒を撒くか、相棒を乗せるか

スキル画面では行動方針も選べます。バランス寄りから、通常攻撃多めまで、だいたい7択です。完全手動ではないので、「このキャラは状態異常屋」「このキャラは削り役」くらいの方針を渡して見守る、が基本です。

（画像: キャラ画面のスキル一覧。装備中の1本と解放済み）

#連携

ここが個人的に好きなところです。単独の技が強いだけだと、パーティを組む意味が薄くなるので、噛み合わせ用の仕組みを2層入れています。

**1. 状態コンボ**  
敵に乗っている状態を、攻撃で「起爆」するやつです。たとえば毒が乗っているところに追撃すると毒爆発、出血に斬撃が重なると出血追撃、冷却中に殴ると粉砕、みたいな感じです。状態を消費して追加ダメージになるので、「誰かが仕込む → 誰かが割る」が成立します。

**2. パーティ連携**  
メンバー同士の協力ボーナスです。名前はこうです。

- **連携斬** — 挑発（守りの行動）のあと、味方の攻撃がしばらく盛られる
- **追い込み** — 誰かがデバフを付けたら、他のメンバーの追撃が乗る
- **治癒連携** — 回復された人が、次の攻撃で少し強くなる

ログには水色っぽい感じで出ます。④の結果画面で「パーティ連携」が効いた戦闘要素に出るのも、だいたいこれです。自動進行だと見逃しがちなので、終わってから「ちゃんと噛み合ったか」を見返せるようにしてあります。

作りたかった体験は単純で、「タンクがヘイト取って、デバフ屋が印を付けて、火力が割る」がオートでも起きる、です。数値は派手すぎないように抑えてありますが、編成を変える理由にはなっています。

甘いところ: まだジョブ専用の派手な連携演出はないです。ログとダメージ色で分かる、という段階です。あとコンボとリンクが同時に起きることもあって、初見は情報量が多いです（慣れると気持ちいい、つもり）。

#必殺技

必殺はスキルとは別ゲージです。下のほうにスキル用と必殺用が並んでいて、溜まったらカットイン付きで発動します。ここは「見てるだけのゲーム」でも一回ちゃんと派手にしたかったので、演出は厚めです。

職ごとに役割を分けています。みんな同じ全体火力だと編成が単調になるので、こうしました。

- **ソードマン（王牙列断）** — 敵全体に大ダメージ＋脆弱。群れもボス周りもまとめて裂く
- **ヴァンガード（タイタンロア）** — 味方全体に防御＋挑発。耐えターンを作る
- **アルケミスト（グランドエリクサー）** — 味方全体を大きく回復。ピンチの保険
- **レンジャー（デッドアイ）** — 単体の超火力＋標的。ボスの削り切り
- **ビーストテイマー（ビーストドミニオン）** — 敵全体に標的／鈍化／毒。仕込み特化の必殺

強い敵（エリートやボス）だと、必殺ゲージは溜まりにくくしてあります。乱発されると緊張感が消えるので、「ここぞ」感を残したかった、という調整です。

（画像: 必殺カットイン。効果の一行が出ているところ）

#まとめ

戦闘の仕込みは、だいたいこの順番で見ると分かりやすいです。

1. 状態異常で「削る／止める／弱らせる」のどれを主軸にするか決める
2. スキル1本で、その主軸を誰が担うか決める
3. 連携が起きる編成か（挑発役・デバフ役・回復役）を意識する
4. 必殺は職の役割どおりに温存／投入する

自動進行でも「自分が何をしたか」が結果に返ってくる、というのがこのゲームの軸です。④の効いた戦闘要素やMVPとあわせて見ると、次の編成が決めやすいはずです。

甘いところは正直まだあります。状態の種類説明、連携の初見ガイド、必殺演出のテンポ調整。ただ、方向性としては「見てるだけのハクスラでも、仕込みで差が出る」を大事にしています。
