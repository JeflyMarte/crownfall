# YouTube解説 文体メモ（Crownfall）

Crownfall の **ゆっくり／VOICEVOX解説動画** の台本文体の正。  
実例SSOT: `docs/devlog/youtube_ep02_script.md`（魅力優先の現行）／概要紹介は `youtube_ep01_script.md`  
手順: `docs/devlog/YOUTUBE_YUKKURI_GUIDE.md`  
Note（制作日記）の熱量口調とは **別物**。混ぜない。

---

## 一文でいうと

**ゲームの魅力を、客観的に、わかりやすく説明する。**  
実況・煽り・専門用語の羅列はしない。下手に出る前置きもしない。

---

## トーン

| やる | やらない |
|---|---|
| です・ます基調 | Noteみたいな「やば／めっちゃ／ほんま」連発 |
| 仕組みと気持ちよさの核を先に言う | 「動画素人」「つたない」「拙い紹介」 |
| 「〜が魅力です」「〜につながります」 | 「温かい目で」「下手で申し訳ありません」 |
| 開発中は事実として短く | アイコン・粗さへの長い自虐 |
| 丁寧ではっきり | 「絶対面白い」「神ゲー」断定／上から宣伝 |

---

## 構成の型（毎回これでよい）

1. **前振り** — 今回何を説明するか（主題を先に）  
2. **経緯**（必要なら）— なぜ作っているか。短く  
3. **何か** — ジャンルと一番の特徴  
4. **魅力** — 核を短く（例: 準備で勝つ／ドロップと振り返り）  
5. **遊び方** — 1ループやシステムを具体的に  
6. **現状** — 開発中は一言で足りる。遊べる芯があるならそれを言う  
7. **向き不向き**（必要なら）— 正直に両方  
8. **締め** — Wiki／次回予告／視聴お礼（自虐なし）  

---

## 文の書き方

- 1文は短め。VOICEVOXが読みやすい長さ  
- 難しい語の直後に、かみ砕きを1文添える  
- 「いちばんの特徴は〜です」「ここからが本丸です」で区切る  
- 比較は控えめに使う（放置に見えがち／でも準備が雑だと全滅、など）  
- Task名・ファイルパス・社内用語は出さない  
- 世界観の根幹ネタバレはしない  

### 言い回しのストック（この系統で揃える）

- 今回は〜に絞ります  
- ここからが、ハクスラの本丸です  
- 魅力の芯は〜にあります  
- そこが、このゲームの〜です  
- 短くまとめます  
- いまも開発を続けていますが、〜はすでに遊べます  
- 詳しいデータは攻略ウィキにまとめています  
- ご視聴ありがとうございました  

### 使わない（下手に出る系）

- 動画はまだまだ下手で〜  
- 説明もつたないかもしれません  
- 温かい目で見てもらえたら〜  
- 足りないところ、粗いところも多いと思います（長めの自虐）  
- 拙い紹介にお付き合いいただき〜  
- 動画素人です（説明欄含む）

## 第1本で確定した中身の軸

以降の回でも、ブレない前提として残す。

- **作者投稿**であること（必要なら短く。下手出しはしない）  
- **ディアブロ／ボーダーランズ系ハクスラが好き**で作り始めたこと  
- **自分では殴らない／指揮官**が最大の特徴  
- **装備・属性・編成の準備**が魅力の芯  
- **開発中**は事実として短く。遊べるループがあるならそれを優先して伝える

## Note との使い分け

| | Note | YouTube解説 |
|---|---|---|
| 話し手 | 亜凸ㇺ俊（制作日記・本音） | 案内ナレ（VOICEVOX）＋魅力の客観説明 |
| 目的 | 制作日記・感情・コスト感 | 初見に「何が面白いか／どう遊ぶか」 |
| 口調 | 口語・熱い | 丁寧・はっきり・自虐しない |

同じ話題でも、文章は **このメモ側** に合わせる。

## 第2本の軸（システム具体）

- テーマは **一日のループ＋装備ドロップ＋結果＋鍛冶**（A+B統合、最大約8分）
- 「なぜ殴らないか」の長い設計談は本編にしない（第1回で触れた前提の再掲は短い導入のみ）
- 台本正: `youtube_ep02_script.md`

---

## 第3本の軸（戦闘の見方）

- テーマは **自動戦闘の画面の見方**（ログ／技・必／弱点・属性／天候／連携／状態異常／結果の効いた要素）
- 作り方は第2回と同じ **音声先行・1文=1ショット**（通し1本に台本を縛らない）
- 実況口調にはしない。第2回のドロップ／鍛冶深掘り、キャラ個別の長い紹介は本編ではやらない（編成は次回以降）
- 旧案「モーンゲート通し1本」は不採用（通し映像は素材流用可）
- 台本正: `youtube_ep03_script.md`

## キャラ紹介シリーズ（通し番号なし）

- **個別投稿**。ep01/02/03 の続き番号には乗せない
- 1本＝1キャラ。主題は **同職・他役との差別化** と **組めるビルド**
- 作り方は第2回と同じ **音声先行・1文=1ショット**
- ロアの長い語り・実況口調はしない
- 第1本: アルド（案A・差別化＋出血主砲1本）— 台本正: `youtube_chr_ald_script.md`
- フォルダ例: `docs/devlog/yt_chr_ald/`
