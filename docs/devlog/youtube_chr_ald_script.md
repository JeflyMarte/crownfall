ずんだもん: 平たい攻撃アップじゃないんですね。

ずんだもん: あ、アイコン残ってる。

めたん: 自動でも状況が読めます。
めたん: ここがアルドの強さの核です。

めたん: はい。だから戦闘時間が長いほど差が出ます。
