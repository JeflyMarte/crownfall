# 01 — ゲーム概要（現行）

## タイトル

Crownfall（クラウンフォール）

## ジャンル・プラットフォーム

- スマホ向け（縦画面 **720×1280**、`aspect=keep`）
- 2D 見下ろし型 RPG
- **自動探索** ＋ **自動戦闘**
- ハクスラ（装備収集・ビルド）
- ローグライト要素あり（ラン単位の探索）
- エンジン: Godot 4.6.x / GDScript
- 配信: **iOS App Store**（日本語）。基本無料＋アプリ内課金（課金必須ではない設計）

## コアコンセプト

プレイヤーは冒険者を **直接操作しない**。  
探索隊の **指揮官**として、方針・装備・編成・ビルドを決め、**戦闘は観察する**。

目標体験: 「見るだけなのに面白い」（Combat Vision）。  
キャッチ: **操作しない。準備で勝つ。**

## コア体験（ループの核）

1. 拠点で備え（編成・装備・鍛冶・招待状・発掘）
2. ダンジョン（本編／イベント／深層）を選ぶ
3. 自動探索を見守る（部屋ステップ進行）
4. 帰還して報酬・成長を確認
5. 装備を更新し、また出る

## 勝ち筋

「強い武器を拾う」だけでなく、**強い組み合わせを作る**ゲーム。

主な柱:

- 状態異常（毒／炎上／感電／冷却 等）
- 属性弱点（5属性 × 弱点時 ×1.25）
- クリティカル
- 探索・発見（図鑑／Codex）
- 防御・生存（簡易ヘイト・イニシアチブ）
- 機巧士の仕掛け（敵行動で作動）／エンシェントセット加護

## 製品として遊べる範囲（重要）

| 項目 | 現行 |
|---|---|
| 本編 | メイン①〜⑤ノーマル（直列解放）。②は①クリアのみ |
| Hard／Nightmare | メイン5ノーマル全クリア後（本編） |
| 寄り道（side） | データ残置・**選択不可** |
| 降臨 | 時環／境界／潮脈王（時間帯・15F） |
| 征討 | 地図なき主／星炉の寝主（常設・20F・⑤クリア後） |
| 深層 | Biome×5 無限（親クリア後） |
| 曜日イベント | ダック／レイヴン／スカラベ／影狩り／ロックバイソン等 |
| 招待状 | **常時 ON**（単発魔晶石＋チケット）。機巧士3含む |
| 魔晶石発掘 | 拠点・日次1回 |

## プレイヤーロール

- 隊長（指揮官）— 名前入力あり。調査許可ランク D〜S
- 冒険者パーティ — 人間枠＋ペット
- NPC 案内 — 記録官 **ニーナ**（導入・拠点おすすめ）

## 何をしないか（設計境界）

- ラン中の細かい手動操作・リアルタイム位置操作は未実装（将来 Vision）
- 操作講習型チュートリアルは採用しない
- 鑑定屋への必須導線は現行オミット
- PvP／大規模オンラインなし
