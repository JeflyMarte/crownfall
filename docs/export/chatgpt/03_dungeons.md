# 03 — ダンジョン（本編・降臨・征討・深層・イベント）

## 設計単位

ダンジョンは単なる「攻略マップ」ではなく **生態系単位（Biome）**。

| 種別 | 役割 | 配信 |
|---|---|---|
| メイン | ストーリー脊柱・次帯解放の鍵。Biome あたり **5章**（x-1〜x-5） | ✅ |
| 寄り道（side） | 素材・整備。必須ゲートにしない | ❌ オミット（データ残置） |
| 降臨 | 時間帯の短編高難度・エンシェントセット | ✅ 3本 |
| 征討（apex） | 常設の長編高難度・エンシェント専用 | ✅ 2本（⑤クリア後） |
| 深層（abyss） | 親 Biome クリア後の無限階 | ✅ 5本 |
| 曜日イベント | 日1回の短編ファーム／挑戦 | ✅ |

## 章ルール（本編）

| 項目 | 方針 |
|---|---|
| 1章 = 1ラン | EXIT で拠点戻り |
| x-1〜x-4 | Boss **なし**。floor／敵Lvは章ごと |
| x-5 | 多フロア＋**最終Fで Boss** |
| 解放 | x-5 Boss 初回討伐（ノーマル）で次メイン第1章 |
| ②解放 | ①クリアのみ（調査ゲージは解放非関与） |

## 危険度ティア

同一ダンジョンに **ノーマル／ハード／ナイトメア**。  
本編解放は前ティアクリア。敵Lv・レア重み・報酬が上昇。  
降臨・征討は出現中（征討は常設）に N/H/NM を自由選択。

| 枠 | 長さ | 配信 | 専用報酬の核 |

### 降臨（3本）

毎日 JST・各1時間・**同時オープンしない**（毎時ちょうど1本）。出現中は日次回数制限なし。

| 表示 | 潜る場 | Boss | 出現（JST） |
|---|---|---|---|
| 【時環の共鳴龍クロノス・ウェーブ】降臨 | 時王の霊廟 | クロノス・ウェーブ | 0 / 3 / 6 / 9 |
| 【境界の番ヴァルガード】降臨 | ストームクラウン境界廊 | ヴァルガード | 1 / 4 / 7 / 10 |
| 【潮脈王ネレイオン・デプス】降臨 | 沈没旗艦下 | ネレイオン・デプス | 2 / 5 / 8 / 11 |

セット例: 時環／境界／潮脈の契（被ダメ軽減・回復寄りなど）。初回エンシェント確定寄り・再周回は確率。

## 放浪希少種（ラン中差し込み）

- コズミックダック — 高EXP・短時間で逃走・装備なし
- 宝冠レイヴン — ELITE級・装備ドロップ高め
- ゴールデンスカラベ — 高ゴールド・逃走・装備なし
- 影狩り — 強敵・EXP／金／レアドロップ厚め
- 出現率は周回帯（N／H／NM）で上昇
- 降臨・征討では放浪オフの帯あり

## 部屋種別（概念）

START / COMBAT / EVENT / TREASURE / ELITE / MID_BOSS（エリート扱い）/ BOSS / EXIT など。  
実際の並びは章の `floor_count` と重みで生成。

## 罠

ダメージは **最大HP割合**（例: 単体10%/15%、全体は低め％）。探索・罠部屋で適用。

## バランスメモ（要約）

- 敵は「しっかり危ない」方向（味方ボーナス抑制・群れ圧力など章／帯で差）
- モーンゲートNは序盤緩和（群れ上限・ソロ倍率など）あり
- ステは過去に ×8 スケール済み
