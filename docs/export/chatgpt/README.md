---

## 何のためのフォルダか

ChatGPT に「**いま実装されてプレイできる体験**」を渡すための要約パッケージ。  
古い β封鎖（①のみ）や将来構想を現行扱いしない。追加コンテンツ相談でも、まずこのフォルダを正にする。

---

## ChatGPT への渡し方（推奨）

### 最短（追加コンテンツ相談・バランス・文言）

1. 本 `README.md`
2. `00_INDEX.md`
3. `01`〜`07` と `09_product_status.md`（話題に関係する章だけでも可）

### 世界観・ロア相談を含む場合

上記に加え `08_world_brief.md`  
**大幅深掘り**はサブフォルダ `world/`（`world/README.md` から）

### 注意

- **一度に全部を貼るとコンテキストを圧迫**する。相談テーマに合わせて 2〜4 ファイルから始める
- 矛盾が出たら「`docs/export/chatgpt` の記述を正とし、古い game 仕様の歴史節は無視」と指示する
- このフォルダは **要約**。数値の最終確認が必要なら本体 `docs/specs/game/` / `docs/specs/decisions/` を参照
- 1本で渡したい場合は `docs/external/Crownfall_ChatGPT評価用_ゲーム仕様.md`（自己完結版）
