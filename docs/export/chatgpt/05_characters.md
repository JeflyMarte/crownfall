# 05 — キャラクター・ジョブ・ガチャ・ペット

## ジョブ（6種・上位／下位職なし）

| ジョブ | ざっくり役割 |
|---|---|
| ソードマン | 近接アタッカー |
| レンジャー | 遠距離 DPS |
| ヴァンガード | タンク／ヘイト |
| アルケミスト | 呪術・回復・デバフ |
| ビーストテイマー | 獣・群れ・ペット連携 |
| **機巧士** | 敵に仕掛けを付け、行動で作動（罠／装炎／破砕） |

ジョブはスキルリストだけでなく **AI 行動思想**を決める（Combat Vision）。  
機巧士は **BASE_ROSTER（開始5）に含めない**。招待状助っ人として獲得。

## 編成

- 人間: 最大 **4人**（陣形あり）
- **ペット「ジャック」**: NG開始から随伴。4人枠外・★1・装備不可・パッシブなし・常時前衛・共有EXP
- 編成UIは入れ替え／おすすめ／陣形で **即確定**（フッター保存廃止。プリセット保存は別）

## スターター加入

- 開始時: **1人選択**
- 各 Biome の x-5 クリアで初期5が順次加入（β Extra OFF＝本番寄り）
- メイン5の★帯は ★3 寄せ

## 成長

| 項目 | 現行 |
|---|---|
| EXP | ラン成功時、受取対象へ（人間＋ペット） |
| 上限 | Lv99（51〜は逓減。スキル習得は〜50） |
| 成長 | HP/ATK/DEF（`BalanceConfig`・キャラ別倍率・STAT_SCALE） |
| ジョブ進化 | **オミット**（UI非表示・データ残置） |

## スキル習得の目安

職ごとに Lv 到達で習得。装備できるジョブスキルは **1本**（必殺・レジェンド武器スキルは別枠）。  
機巧士は習得7本キット＋キャラ別必殺（助っ人3で必殺を分ける例外あり）。

詳細は本体 `06_キャラクター_ジョブ.md`／`decisions/126_EngineerJob.md`。

## 固有パッシブ

- メイン5＋ガチャ助っ人の固有パッシブあり
- ★帯の職パッシブ自動付与は撤去方向

## 招待状（ガチャ）

| 項目 | 現行 |
|---|---|
| UI名 | **招待状**（召喚という語は避ける） |
| プレイ | 常時 ON |
| ボタン | **単発魔晶石＋チケット**（10連・複数タブなし） |
| プール | 基本助っ人＋**機巧士3**（ブリキ／バルガント／アンヴィ） |
| 重複 | **限界突破**: パッシブ効果×(1+0.1N)、上限+5、還元半減 |
| 演出 | 封書リビール（閉→開封→顕現）。Featured Idle 回転 |

スターター5職はガチャ除外。助っ人はロスター参加・装備可・共有EXP。
