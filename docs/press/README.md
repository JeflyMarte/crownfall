# Crownfall — メディア掲載（プレス）一式

作成: 2026-09-08

## 目的

Crownfall をゲームメディア（4Gamer / ファミ通 / AUTOMATON など）および IT メディア（GIGAZINE / 電ファミ など）に掲載してもらう。

## 方針

切り口を **2 系統に分ける**。同じ文面をどこにでも送らない。

| 系統 | 訴求 | 相手 |
|---|---|---|
| **A. AI 開発ストーリー** | AI エージェントに長期プロジェクトを任せる運用を作った実例 | GIGAZINE、電ファミ、ITmedia、Zenn |
| **B. ゲーム紹介** | 「自分では殴らないハクスラ」 | 4Gamer、ファミ通、AUTOMATON、ゲームキャスト ほか |

GIGAZINE は IT メディアであり、日本語専用の個人開発スマホゲーム単体では通りにくい。**A の切り口でのみ狙う。**

## ファイル

| ファイル | 内容 |
|---|---|
| `FACTSHEET.md` | **全ての土台。**数値・リンク・ピッチ。変更はここから |
| `RELEASE_B_game.md` | ゲーム紹介リリース（メール本文まるごと） |
| `RELEASE_A_ai_dev.md` | AI 開発ストーリー（メール本文まるごと） |
| `MEDIA_LIST.md` | 送付先・窓口・送付順・進捗トラッカー |
| `PRESSKIT.md` | プレスキットの構成手順とスクショ 10 枚の選定 |
| `TRAILER_60s.md` | トレーラー台本（60 秒） |
| `ZENN_DRAFT.md` | 技術記事ドラフト（はてブ経由で GIGAZINE を狙う） |

## 実行手順

### フェーズ 0 — 送る前に必ず埋めるもの

これが揃うまで送っても記事になりません。

- [ ] **App Store の公開 URL** を `FACTSHEET.md` に記入
- [ ] **X アカウントを開設**（記事末の導線として必ず求められる）
- [ ] **連絡用メールアドレス**を決める（普段使いと分けるのが無難）
- [ ] **公式 Wiki が実際に公開稼働しているか確認**（https://crownfall-game.github.io/ ）
- [ ] **4Gamer に事前連絡フォームを送る**（アドレス取得に数営業日かかるので**今すぐ**）

### フェーズ 1 — 素材を作る

- [ ] タイトル画面・拠点ホーム・ダンジョン選択のスクショを撮る（`PRESSKIT.md`）
- [ ] トレーラー 60 秒を作る（`TRAILER_60s.md`）
- [ ] GIF 2 本を切り出す
- [ ] Google Drive にプレスキットを配置し、共有 URL を取得
- [ ] `RELEASE_B_game.md` を PDF 化

### フェーズ 2 — ゲームメディアへ送る（1.0.5 配信日に合わせる）

- [ ] 第 1 波: Game-i / gamebiz / ファミ通.com / 電撃インディー
- [ ] 反応を見て文面を調整
- [ ] 第 2 波: 4Gamer / AUTOMATON / ゲームキャスト / Game*Spark・インサイド

### フェーズ 3 — AI 開発ストーリーで GIGAZINE を狙う

- [ ] `ZENN_DRAFT.md` を仕上げて Zenn に公開
- [ ] X ＋ はてなブックマークで拡散
- [ ] 伸びを確認してから GIGAZINE タレコミ／電ファミ／ITmedia へ `RELEASE_A_ai_dev.md` を送付

## 絶対に守ること

- **「AI が全部作った」と書かない。** 事実と違い、掲載後に信頼を失う。正しい主張は「AI エージェントを開発運用の中心に据えた個人開発」
- **一斉送信しない。** 1 社ずつ、`[メディア名]` を書き換えて送る
- **未実装のものを実装済みのように書かない。** Android / Steam の予定は現時点で未定
