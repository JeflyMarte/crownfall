## メディア別の言い換えメモ

| 相手 | 調整 |
|---|---|
| **ゲームキャスト** | 運営型ゲームの更新情報は原則掲載されない。「新味」を前面に出す。冒頭を「自分では殴らないハクスラを作りました」から始め、リリース告知色を薄める |
| **AUTOMATON** | 事実の正確さを重んじる媒体。誇張表現を削り、実装済み範囲を明確に書く |
| **4Gamer** | 先にフォームで連絡し、リリース送付用アドレスを取得してから送る |
| **電撃インディー** | 自薦可の投稿フォームがある。「作り手が作りたいものを形にした」というトーンに寄せる |
| **Game-i** | 個人開発枠を無料で掲載している。ストア URL と紹介文があれば通りやすい。最初に送る練習台に向く |
