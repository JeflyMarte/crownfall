# トレーラー台本（60 秒）

> **用途:** プレスキット同梱・App Store プレビュー・X 投稿・note 記事の冒頭
> **前提:** ナレーションなし（BGM＋テロップのみ）。記者は音を切って見るので**テロップだけで意味が通ること**が必須
> **素材:** 実機録画（720×1280 縦）。既存 note スクショの画面をそのまま撮り直す

---

## 設計方針

最初の 5 秒で「自分で操作しないゲーム」だと分かること。ここを外すと、ただの自動戦闘 RPG に見えて記事にならない。
テロップは**短く・大きく・2 秒以上**表示する。

## テロップ仕様

- フォント: ゲーム内 UI と同じ書体を使う（統一感が出る）
- 位置: 画面下 1/3。UI と重ならない位置
- 白文字＋黒縁または半透明の帯。ピクセルアート背景の上でも読めること
- 1 枚あたり最短 1.5 秒。読み切れない速さで切らない

## BGM

- ゲーム内 BGM を流用（権利が自分にあるものに限る）
- 0:36 の全滅カットで一瞬音を落とし、0:42 の鍛冶で戻すと構成が締まる

## 制作手順

1. 実機で各画面を録画（iPhone の画面収録。通知を切る、デバッグ表示を消す）
2. 使うカットを切り出す
3. `ffmpeg` または任意の編集ソフトでつなぐ
4. テロップを乗せる
5. 書き出しは H.264 / 720×1280 / 30fps

参考: 既存の VOICEVOX 動画パイプライン（`docs/devlog/YOUTUBE_YUKARI_GUIDE.md`）の ffmpeg 手順を流用できる。ただし**トレーラーはナレーションなしで作る**（記者が使いやすく、多言語化もしやすい）。
