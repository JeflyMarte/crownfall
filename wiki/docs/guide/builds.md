# ビルド例

**キャラ1人ごと**に「最終的にどう育てるか」を決める用。  
パーティ編成は、育てたキャラを組み合わせた結果でよい。

!!! tip "キャラビルドの共通ゴール"
    - 武器は **その職が持てる種**だけ（剣／双刃／弓／杖）
    - 本命は炉研ぎ **+4〜+5**・装備Lvを本体に寄せる
    - 降臨セットは表示レア「**エンシェントレア**」。武器＋鎧＋装飾の3部位で加護
    - 深層Lは親Biomeの99初回確定（[深層](abyss.md)）

装備の拾い優先は[おすすめ装備](recommended-gear.md)。キャラ評価は[Tier](tier.md)。

---

## 読み方

各キャラは次の型で書いてある。

| 欄 | 意味 |
|---|---|
| **固有** | パッシブ核。ビルドの軸 |
| **武器種** | 装備できる種 |
| **ゴール武器** | その子の本命候補（揃ったら炉研ぎ最優先） |
| **防具・セット** | 耐久 or テンポの寄せ先 |
| **向き** | そのビルドが刺さるコンテンツ |
| **相性メモ** | 一緒に出すと伸びやすい相手（参考） |

## 殴り（DPS）

### アルド（ソードマン・初期）

| 欄 | 内容 |
|---|---|
| 固有 | **王炎の覇気** — 攻撃25%で出血 |
| 武器種 | 剣・双刃 |
| ゴール武器 | **継承剣レガート**（神話）／**虚脈の大剣**／炎ならシルヴァリア誓剣・黒陽の双牙／テンポなら時環の刻剣・双剣 |
| 防具・セット | 与ダメ・クリ寄り。時環3部位で手数出血が加速 |
| 向き | 全進行の主火力。まず育てて後悔しにくい |
| 相性メモ | シアン（小鼓舞）／リーヴァ（標的） |

出血は長期戦ほどおいしい。ボス部屋では属性一致武器に持ち替える想定でインベを厚くする。

## 育成キュー（キャラ単位）

1. 今出してる **主軸1人**の弱点武器を+5まで  
2. その子の固有が噛む武器（出血なら手数、標的なら弓、タンクなら生存L）へ載せ替え  
3. 助っ人は **パッシブが欲しい子**から限界突破  
4. 降臨セットは「その子の役割」に合わせて着せる（盾＝アンティーク／手数＝時環）  
5. 深層Lは **その職が持てる深層から**99を取りに行く
