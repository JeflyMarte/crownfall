# ビルド例

**キャラ1人ごと**に「最終的にどう育てるか」を決める用。  
パーティ編成は、育てたキャラを組み合わせた結果でよい。

!!! tip "キャラビルドの共通ゴール"
    - 武器は **その職が持てる種**だけ（剣／双刃／弓／杖）
    - 本命は炉研ぎ **+4〜+5**・装備Lvを本体に寄せる
    - 降臨セットは表示レア「**エンシェントレア**」。武器＋鎧＋装飾の3部位で加護
    - 深層Lは親Biomeの99初回確定（[深層](abyss.md)）

装備の拾い優先は[おすすめ装備](recommended-gear.md)。キャラ評価は[Tier](tier.md)。

---

## 読み方

各キャラは次の型で書いてある。

| 欄 | 意味 |
|---|---|
| **固有** | パッシブ核。ビルドの軸 |
| **武器種** | 装備できる種 |
| **ゴール武器** | その子の本命候補（揃ったら炉研ぎ最優先） |
| **防具・セット** | 耐久 or テンポの寄せ先 |
| **向き** | そのビルドが刺さるコンテンツ |
| **相性メモ** | 一緒に出すと伸びやすい相手（参考） |

## 殴り（DPS）

### アルド（ソードマン・初期）

| 欄 | 内容 |
|---|---|
| 固有 | **王炎の覇気** — 攻撃25%で出血 |
| 武器種 | 剣・双刃 |
| ゴール武器 | **継承剣レガート**（神話）／**虚脈の大剣**／炎ならシルヴァリア誓剣・黒陽の双牙／テンポなら時環の刻剣・双剣 |
| 防具・セット | 与ダメ・クリ寄り。時環3部位で手数出血が加速 |
| 向き | 全進行の主火力。まず育てて後悔しにくい |
| 相性メモ | シアン（小さな鼓舞）／リーヴァ（標的） |

出血は長期戦ほどおいしい。ボス部屋では属性一致武器に持ち替える想定でインベを厚くする。

---

### 火鷹（ソードマン・★4）

| 欄 | 内容 |
|---|---|
| 固有 | **血潮の代償** — 撃破で鼓舞。たまに行動スキップ |
| 武器種 | 剣・双刃 |
| ゴール武器 | 手数の双刃（根葬の双刃／黒陽の双牙／時環双剣）。雑魚が多い周回向き |
| 防具・セット | 時環でテンポ。耐久は最低限で火力寄せ |
| 向き | ②炎周回・曜日短編。ボス単体部屋はスキップ税が重い |
| 相性メモ | シアン／セリン（スキップ事故の保険） |

「刈り役」。ボス専用枠にはしにくい。

---

### カイダ（ソードマン・★2）

| 欄 | 内容 |
|---|---|
| 固有 | **闘技場の切っ先** — 半血以下で与ダメ+30% |
| 武器種 | 剣・双刃 |
| ゴール武器 | **虚脈の大剣**（低HPほど伸びるので相性良）／継承剣レガート |
| 防具・セット | HPを下げすぎない中庸。紙にすると即死する |
| 向き | 上級者の条件付き砲台。深層ロマン |
| 相性メモ | セリン（落とさない）／ヴァルデン（壁） |

半血を維持する運用が前提。初心者の主軸にはしない。

---

### レノール（アルケミスト・★2）

| 欄 | 内容 |
|---|---|
| 固有 | **封緘の切っ先** — 与ダメ+12%／被ダメ+10% |
| 武器種 | 杖・双刃 |
| ゴール武器 | 高ATK杖（ウンブラ・テルミナス／セラディオン杖／時環杖）or ガラス双刃 |
| 防具・セット | 被ダメ増を相殺するHP防具。アンティーク寄せが無難 |
| 向き | 短編・弱点一致の火力枠 |
| 相性メモ | ヴァルデン／セリン（紙を守る） |

平％火力。盾とヒーラーがいない編成では爆発する。

---

### リーヴァ（レンジャー・初期）

| 欄 | 内容 |
|---|---|
| 固有 | **狙印の刻** — 攻撃25%で標的（被ダメ↑） |
| 武器種 | 弓・剣 |
| ゴール武器 | **虚潮の長弓**（印爆発と相性）／ファロス・フレア／アンティークアロー／シャドウコード |
| 防具・セット | クリ・攻撃速度。時環で標的頻度↑ |
| 向き | シナジー核。単体火力というより「味方のダメ床上げ」 |
| 相性メモ | 虚潮持ちの別レンジ／アルド（出血＋標的） |

自分で虚潮を持つビルドもアリ（弓）。剣持ちなら標的役に徹する。

---

### シアン（レンジャー・★3）

| 欄 | 内容 |
|---|---|
| 固有 | **影からの号令** — 開幕小さな鼓舞。必殺と組むと追加ダメ |
| 武器種 | 弓・剣 |
| ゴール武器 | 必殺が回る手数武器（時環弓／斉射の地平弓／虚潮） |
| 防具・セット | 時環3部位が本命（テンポ＝必殺回転） |
| 向き | 攻めサポ兼レンジ。どの進行にも差し込める |
| 相性メモ | アルド／火鷹／レノール（鼓舞受け） |

「バッファー兼DPS」。純ヒーラー枠ではない。

---

### ルーシェ（ビーストテイマー・★3）

|---|---|

## 育成キュー（キャラ単位）

1. 今出してる **主軸1人**の弱点武器を+5まで  
2. その子の固有が噛む武器（出血なら手数、標的なら弓、タンクなら生存L）へ載せ替え  
3. 助っ人は **パッシブが欲しい子**から限界突破  
4. 降臨セットは「その子の役割」に合わせて着せる（盾＝アンティーク／手数＝時環）  
5. 深層Lは **その職が持てる深層から**99を取りに行く
