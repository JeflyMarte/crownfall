# ビルド例

「最終的にこの編成を目指す」用の **ゴールビルド**。  
顔は入れ替えてよい。大事なのは **役割・属性・装備の型**。

凡例: 前＝前衛寄り／後＝後衛寄り。オトモは枠外（常時前衛寄り）。

!!! tip "共通のゴール条件"
    - 人間枠は最大4＋オトモ1
    - 武器は **職の装備可能種**のみ（[ジョブ](../data/jobs.md)）
    - 本命装備は炉研ぎ **+4〜+5**・装備Lvを本体に寄せる
    - 降臨セットはレア表示「**エンシェントレア**」。3部位で加護

進行中の型はページ下部。装備の拾い優先は[おすすめ装備](recommended-gear.md)。

---

## G1 — 深層99サバイブ（まず死なない）

**ゴール:** 各深層の **33／66／99** を安定到達。無限エンドの本命。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | **ヴァルデン** | 被ダメカットの壁。高階の保険 |
| 前 | **ガレン** | 被ダメ軽減＋注目。二枚盾 |
| 後 | **セリン** | 部屋またぎ全体回復。周回の命綱 |
| 後 | 属性DPS（**アルド**／火鷹／リーヴァ） | 親Biome弱点を殴る |
| オトモ | **アッシュ** | 守り。深層は崩しより生存 |

### 装備の狙い

| 部位 | 本命候補 | メモ |
|---|---|---|
| DPS武器 | 親Biome弱点の★〜神話／深層L | 深層敵は親と同じ弱点傾向 |
| 盾側 | 澱みの封杖（杖職）／裂氷の双爪（双刃） | 生存パッシブ持ちを盾・準盾へ |
| 防具・装飾 | HP・防御が厚い個体 | アンティーク3部位が取れたら耐久さらに安定 |
| オトモ | アッシュ固定寄り | インクは火力欲が出てから |

### 向いてる場所

- 全深層の初回99取り
- Hard／Nightmare の初挑戦

!!! warning "やりがち失敗"
    盾1枚＋ガラス3人で99を殴りに行く。66までは行けても99前で溶ける。

## G2 — 時環テンポ（降臨セット完成形）

**ゴール:** **時環の刻** 3部位＋手数編成で、雑魚部屋を最短刈り。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | ガレン or ボルグ | 最低限の壁（テンポ優先なら薄めでも可） |
| 中 | **アルド**／火鷹 | 主火力。剣・双刃で手数 |
| 中 | **シアン** | 小さな鼓舞＋必殺シナジー |
| 後 | リーヴァ or 電気レンジ | ボス／耐性部屋用の第二属性 |
| オトモ | **インク** or ジャック | 崩しでテンポ加速 |

### 装備の狙い

| 部位 | 本命 | 効果 |
|---|---|---|
| セット | **時環の刻** 武器＋鎧＋宝珠 | 速度+15%／スキルCD・詠唱−15% |
| 武器種 | 剣／双刃／弓／杖（職に合う刻武器） | 電気寄り。降臨「時環の共鳴龍」 |
| サブ | 深層の根葬の双刃など | セット未所持枠の火力補強 |

### 向いてる場所

- 曜日短編・周回
- ウィスパー／ミストの弱点一致周回
- 降臨クロノス再周回

入手: [イベント](events.md)（JST 0／3／6／9時帯）

## G3 — アンティーク耐久（降臨セット完成形）

**ゴール:** **アンティーク** 3部位で被弾に強いエンドタンク編成。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | **ヴァルデン** | 主盾 |
| 前〜中 | **ガレン** or 聖属性近接 | サブ盾＋殴り |
| 後 | **セリン** | 回復 |
| 後 | 聖レンジ（リーヴァ／シアン） | ④や聖弱点を安定処理 |
| オトモ | **アッシュ** | 耐久三角を完成 |

### 装備の狙い

| 部位 | 本命 | 効果 |
|---|---|---|
| セット | **アンティーク** 武器＋鎧＋アミュレット | HP・与ダメ+12%／被ダメ−11% |
| 武器 | アンティークブレイド／アロー等 | 聖寄り。降臨「境界の番」 |
| 追加生存 | 澱みの封杖・裂氷の双爪 | セット外の生存Lを誰かに持たせる |

### 向いてる場所

- 深層66〜99
- Hard／NM
- ブラックショア系（聖が刺さる）

入手: [イベント](events.md)（JST 1／4／7／10時帯）

## G4 — オトモ極大

**ゴール:** 人間は支える側。**ジャック／アッシュ／インク**が主役。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | ガレン | 人間側の壁（注目） |
| 中 | **ミレイ** | ペット与ダメ+20% |
| 中 | **ネリ** | ペット与ダメ+15%＆防御+5% |
| 後 | セリン or シアン | 回復 or 小さな鼓舞 |
| オトモ | 状況切替 | 守り＝アッシュ／崩し＝インク／万能＝ジャック |

### 装備の狙い

- 人間の武器は「死なない＋弱点属性」で十分。オトモに装備は付かない
- ミレイ／ネリは限界突破を優先（パッシブ核）
- 解放: アッシュ＝②調査100%／インク＝④調査100%（初回のみ）

### 向いてる場所

- ②〜⑤の安定周回
- オトモ好きのメイン編成
- 深層はアッシュ寄せが無難

詳細は[オトモ](pets.md)。

## G5 — 印爆発（虚潮＋標的）

**ゴール:** **虚潮の長弓**の潮汐印爆発を軸に、リーヴァの標的で被ダメを盛る。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | ヴァルデン or ガレン | 壁。弓パは後衛が多いので盾必須 |
| 中 | **リーヴァ** | 攻撃25%で標的。被ダメシナジー |
| 後 | 弓職（シアン／イヴァル等）＋**虚潮の長弓** | 印4積で爆発（ヒット150%追撃） |
| 後 | セリン | 生存 |
| オトモ | アッシュ（安定）／インク（攻め） | 好み |

### 装備の狙い

| 本命 | 入手 | メモ |
|---|---|---|
| **虚潮の長弓** | 無限ブラックショア 99初回 | 弓職・BT向け。闇属性 |
| 標的源 | リーヴァパッシブ／スキル | 印爆発のダメージ床上げ |
| セット | 時環（手数）or アンティーク（耐久） | 鎧・装飾だけセットでも可 |

### 向いてる場所

- ブラックショア深層・聖／闇が通る部屋
- ボスの長期戦（印が貯まる）

!!! note "職注意"
    虚潮は **弓**。ソードマンには持たせられない。

## G6 — Hard／Nightmare 突破

**ゴール:** メイン5の Hard → NM キャンペーンを通す編成。

| 枠 | 例 | 役割 |
|---|---|---|
| 前 | **ヴァルデン** | 必須級の壁 |
| 前 | **ガレン** or ボルグ | 二枚盾 or 回避 |
| 後 | **セリン** | 回復。NMでは優先度最高クラス |
| 後 | 属性特化DPS | その章の弱点（炎／電／聖など） |
| オトモ | **アッシュ** | 守り固定推奨 |

### 装備の狙い

- アンティーク3部位があれば最優先で着せる
- なければ深層生存L（澱み／裂氷）＋弱点武器+5
- 神話「葬冠の大剣」等が出たら近接DPSへ

### 向いてる場所

- Hard／NM全般（[Hard／Nightmare](hard-nightmare.md)）
- 深層66帯の予習にもなる

## ゴール武器の優先度（ざっくり）

取る順番の目安。所持と職で前後してよい。

| 優先 | 何を取るか | 理由 |
|---|---|---|
| 1 | 降臨セットどちらか3部位 | エンドの土台（速度 or 耐久） |
| 2 | 常用職に合う深層L 1本 | 99初回確定。虚潮／根葬／虚脈など |
| 3 | もう一方の降臨セット | コンテンツ切替用 |
| 4 | 残りの深層L | 職カバーと遊び幅 |
| 5 | 神話・高個体の育成 | 出たら育てる。狙って出せない |

深層Lの効果要約は[深層](abyss.md)、一覧は[おすすめ装備](recommended-gear.md)。

## 進行中の型（ゴールまでの仮組み）

ゴール装備が揃う前の仮編成。細かい進行はここを潰しながらでよい。

| 型 | ざっくり | 次のゴール |
|---|---|---|
| ①〜②安定 | ガレン＋アルド＋電気／聖＋回復。ジャック | → G1／G4 |
| ②炎周回 | 炎特化＋シアン。インク解禁後は崩し | → G2 |
| ④聖転換 | 炎特化を捨て聖軸へ | → G3／G5 |
| ガラス短編 | 盾薄＋レノール／火鷹。短編限定 | メインBossでは非推奨 |

序盤ルートは[初心者向け](beginner.md)。

## 編成のルール・オブ・サム

- 人間4のとき **盾ゼロは事故率が高い**
- **属性2種**（道中／ボス）を分けると①や④が楽
- スキルは1人1本。ダンジョン向けに付け替え
- 推し詰めはA。ただし武器種制限と属性は裏切るな
- 「ゴール」は装備が揃ってから。揃う前に深層99を無理しなくてよい
