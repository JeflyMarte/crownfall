## イベントダンジョン（曜日限定）

日次 **1回**。平日は担当曜日、**土日は全開放**（日付境界は JST 5:00 目安）。

詳細攻略 →[イベントダンジョン](events.md)

| 曜日 | ダンジョン |
|---|---|
| 月 | コズミックダックの裂け目 |
| 火 | 宝冠レイヴンの巣 |
| 水 | 砂金の巣穴 |
| 木 | 影狩りの狩場 |
| 金 | 岩角の群れ道 |
| 土日 | 上記すべて |

多くは放浪敵の出現を抑えた専用ルート。報酬・敵構成は通常メインと異なる。

## 深層（エンドコンテンツ）

親 Biome のノーマルボスを倒すと、対応する深層が解放される。

詳細攻略 →[深層攻略](abyss.md)

| 深層 | 親 |
|---|---|
| 無限モーンゲートの最果て | ① |
| 無限ウィスパーウッドの最果て | ② |
| 無限ミストフェンの最果て | ③ |
| 無限ブラックショアの最果て | ④ |
| 無限フロストリッジの最果て | ⑤ |

- **33 / 66 / 99** にマイルストーン報酬
- 99以降は無限階。深層限定レジェンド武器のチャンスあり（初回99で本体付与）
- 難度は階が進むほど上昇

---

## 放浪（希少種）

メイン系の探索中に、希少な放浪敵が出現することがある（コズミックダック、宝冠レイヴン、ゴールデンスカラベ、影狩りなど）。ギルド情報誌の予兆も参考になる。イベントDGでは多くが無効。
