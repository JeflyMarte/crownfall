## イベントダンジョン

詳細攻略 →[イベントダンジョン](events.md)

### 曜日限定（短編・日次1回）

平日は担当曜日、**土日は全開放**（日付境界は JST 5:00 目安）。多くはボス無し・専任敵。

| 曜日 | ダンジョン |
|---|---|
| 月 | コズミックダックの裂け目 |
| 火 | 宝冠レイヴンの巣 |
| 水 | 砂金の巣穴 |
| 木 | 影狩りの狩場 |
| 金 | 岩角の群れ道 |
| 土日 | 上記すべて |

### 時間帯降臨（ボスあり・セット装備）

毎日決まった時刻帯のみ門が開く。推奨Lv高め（エンド寄り）。

| 降臨 | 時間帯（JST・各1時間） | ボス | セット |
|---|---|---|---|
| 時環の共鳴龍　降臨 | 0／3／6／9時 | クロノス・ウェーブ | 時環の刻 |
| 境界の番　降臨 | 1／4／7／10時 | ヴァルガード | アンティーク |

初回ボスでセット3部位。3部位揃いで加護。Boss横断 →[Boss攻略まとめ](bosses.md)

## 深層（エンドコンテンツ）

親 Biome のノーマルボスを倒すと、対応する深層が解放される。

詳細攻略 →[深層攻略](abyss.md)

| 深層 | 親 |
|---|---|
| 無限モーンゲートの最果て | ① |
| 無限ウィスパーウッドの最果て | ② |
| 無限ミストフェンの最果て | ③ |
| 無限ブラックショアの最果て | ④ |
| 無限フロストリッジの最果て | ⑤ |

- **33 / 66 / 99** にマイルストーン報酬
- 99以降は無限階。深層限定レジェンド武器のチャンスあり（初回99で本体付与）
- 敵Lvは階と1:1ではなく **階アンカー表**（例: 1F=Lv1、33F=Lv32、66F=Lv80、99F=Lv110）。詳細は[深層](abyss.md)

## 放浪（希少種）

メイン系の探索中に、希少な放浪敵が出現することがある（コズミックダック、宝冠レイヴン、ゴールデンスカラベ、影狩りなど）。ギルド情報誌の予兆も参考になる。イベントDGでは多くが無効。

探索開始時に **天候**（快晴／雨／夜／霧／炎天／吹雪）が1つ決まり、属性の与ダメ補正やBiome偏りがある。情報誌に天候枠があるときは効果も載る。
