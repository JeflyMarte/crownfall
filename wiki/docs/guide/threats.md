# 要注意敵

「こいつウザい／痛い／事故る」リスト。数値は基礎値なので Hard・深層ではもっと凶悪。

---

## 即メモ（危険度SS）

| 敵 | どこ | なぜヤバイ | 対策雑 |
|---|---|---|---|
| **影狩り** | 木イベ・放浪 | 通常なのに ATK295級。被弾で鈍化（約30%） | **聖**で速攻。日次1回を舐めない |
| **セルディオン** | ① 1-5 | 初見殺し枠。出血 | 道中炎／ボスは**電気・闇** |
| **ネレイオン** | ④ 4-5 | HP厚め。冷却。**炎耐性** | ④で炎特化持ち込み禁止。**聖／氷** |
| **グランヴェル** | ② 2-5 | 再生イメージのタンク熊。出血 | 全部**炎**で押し切れ |
| **エルディオン** | ⑤ 5-5 | 防御厚め。冷却。電気も闇も耐性 | **炎**（影響属性は氷） |

## 状態異常チートシート

遭遇したら「何を撒いてくるか」だけ見ろ。

| 撒きがち | 代表 |
|---|---|
| **スタン** | クロックモス、アンカーロード、オルドレクス、マンモス |
| **冷却** | ネレイオン、エルディオン、ワイバーン、グレイオス、潮灯 |
| **毒** | モルドガル周り、ワスプ、ミラーボア、沼勢 |
| **出血** | セルディオン、グランヴェル、大爪刀、鮫勢 |
| **標的** | 深海司祭、ロイヤルシャーク、ヴォイドテンタクル |
| **恐怖** | 夜沼 |
| **鈍化** | 影狩り（被弾約30%） |

回復・ガード・前衛の厚みがないと、状態異常部屋で一気に崩れる。
