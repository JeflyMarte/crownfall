# はじめに

Crownfall は、プレイヤーが冒険者を直接操作しない **自動探索型** のハクスラRPG。あなたは探索隊の **指揮官** として、戦う前の準備——編成・装備・方針——で勝敗を決める。

---

## 導入の流れ

初めて起動すると、おおむね次の順で拠点へ入ります。

1. 世界観イントロ
2. 隊長名の入力
3. 案内役ニーナとの対話
4. **初期メンバー1人**を選ぶ（以後の探索隊の核）
5. 拠点ホームへ

オトモの **ジャック** は開始時点から随伴します（人間4人枠の外・常時前衛・装備不可）。

各 Biome の **×-5（ボス章）を初回クリア**すると、未加入の初期仲間が候補になります。加入は結果画面ではなく、**拠点に戻ったあと**（セリフ → 招待状風のリビール）で行われます。

---

## コアループ

```
拠点で編成・装備・鍛冶を整える
      │
      ▼
ダンジョンを選ぶ（メイン／イベント／深層）
      │
      ▼
自動で探索（部屋を進み、敵と自動戦闘）
      │
      ▼
リザルト（経験値・ゴールド・魔晶石・ドロップ）
      │
      ▼
強化して再挑戦・次の章へ
```

| 段階 | やること |
|---|---|
| **編成** | 人間最大4人＋陣形。オトモは枠外。→[ジョブ](../data/jobs.md) |
| **装備** | 職ごとに装備できる武器種が決まっている。→[装備と鍛冶](equipment.md) |
| **ダンジョン** | 推奨レベルを見て挑戦。ボスは各 Biome の **×-5**。→[進行とダンジョン](progression.md) |
| **自動探索** | 隊が部屋を進み、遭遇で[自動戦闘](combat.md)へ |
| **リザルト** | EXP・ゴールド・魔晶石・装備／素材 |
| **拠点強化** | 鍛冶・招待状・調査室・日課などで次の探索に備える |

## 拠点で使えるもの（要約）

詳細は[拠点ガイド](hub.md)。

- **ダンジョン選択** — メイン5 Biome／曜日イベント／深層
- **鍛冶屋** — 生産・炉研ぎ・錬成・分解
- **招待状** — 魔晶石またはチケットで助っ人を招く
- **調査室** — 配置調査で調査ゲージを進める（図鑑・完全調査景品。②解放には不要）
- **図鑑** — 世界観／キャラ／手引き（実績タブは現行非表示）
- **日課・ギルド情報誌** — 毎日の軽い目標、野外の話題、天候の効果（枠があるとき）

---

## 指揮官としての要点

- **弱点を突く** — 敵の弱点[属性](elements.md)に合った武器で与ダメアップ（耐性属性は逆に軽減）
- **職に合う武器** — 職の装備可能種以外は付けられない
- **陣形とオトモ** — 前後列とジャック／アッシュ／インクの役割を意識する
- **調査を進める** — 潜行（本編）が主、調査室が副。②は **①クリアのみ**（調査ゲージは解放非関与）
