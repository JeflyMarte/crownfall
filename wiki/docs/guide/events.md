# イベントダンジョン攻略

イベントタブから入る短編。大きく **曜日限定** と **時間帯降臨** の2系統がある。

| 系統 | ルールの目安 |
|---|---|
| **曜日限定** | 平日は担当曜日のみ／**土日は全開放**。各 **日次1回**。ボス無し・専任敵 |
| **時間帯降臨** | 毎日決まった時刻帯のみ門が開く。ボスあり。専用 **セット装備** |
| 日付境界 | おおむね **JST 5:00**（曜日系） |
| 放浪 | 原則 **無効** |

詳細データ →[ダンジョンデータ](../data/dungeons.md)

## 月曜：コズミックダックの裂け目

濃いエルダ環境に現れる **コズミックダック** 専任。序盤から挑戦しやすい短編。

| 項目 | 内容 |
|---|---|
| 推奨／敵Lv | 5／3 |
| 弱点 | **炎** |
| 群れ | 出現しうる（2〜3体） |

!!! tip "序盤の日課枠"
    炎武器があれば十分。メイン①の合間に回して素材・経験の足しにする。

→ [コズミックダック](../data/monsters.md#cosmic_duck)

| 項目 | 内容 |
|---|---|

→ [宝冠レイヴン](../data/monsters.md#crown_raven)

## 時間帯降臨（ボスあり）

曜日に関係なく、**決まった時刻帯だけ**挑戦できるラスボス級イベント。推奨Lvは高め。戦力はメイン⑤前後〜エンド想定。

| 降臨 | 時間帯（JST・各1時間） | ボス | 弱点 | セット |
|---|---|---|---|---|
| **時環の共鳴龍　降臨**／時王の霊廟 | 0・3・6・9時 | 時環の共鳴龍クロノス・ウェーブ | **電気／聖** | **時環の刻** |
| **境界の番　降臨**／ストームクラウン境界廊 | 1・4・7・10時 | 境界の番ヴァルガード | **聖／電気** | **アンティーク** |

- N／H／NM あり（曜日短編より重い）
- ボス撃破ごとにエンシェント装備 **1個確定**（未所持部位優先。専用レリックは無し）
- 武器＋防具＋装飾の **3部位揃い**でセット加護が発動（パッシブ枠は消費しない）

### 時環の刻（クロノス）

| 部位 | 例 | 属性の匂い |
|---|---|---|
| 武器 | 時環の刻剣／双剣／杖／弓 | 電気寄り |
| 防具 | 時環の刻鎧 | — |
| 装飾 | 時環の刻宝珠 | — |
| **加護** | 行動速度 +15%／スキルCD・詠唱 −15% | テンポ特化 |

→ [クロノス・ウェーブ](../data/monsters.md#chronos_wave)／[Bossまとめ](bosses.md)

### アンティーク（ヴァルガード）

|---|---|---|
| 武器 | アンティークブレイド／デュアル／ロッド／アロー | 聖寄り |
| 防具 | アンティーク鎧 | — |

!!! tip "時刻を逃すな"
    門が閉まっている時間帯は入れない。情報誌やダンジョン選択の開放表示を見る。戦力不足なら曜日短編・深層で整えてから。

## 攻略の共通指針

- **属性を合わせる** — 各イベントは弱点と影響属性が揃っているものが多い
- **メイン進行の合間に** — 曜日系は日次1回。土日でまとめ打ちも可
- **降臨はエンド枠** — セット装備目的で時間帯を狙う
- **放浪は出ない** — 希少種本体がプールにいる設計。情報誌の放浪予兆とは別枠
- **難度差** — ダック／スカラベは軽め、影狩りは重い。降臨は別次元
