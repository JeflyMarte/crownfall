# 招待状（ガチャ）ガイド

拠点下ナビの **招待状**。魔晶石（またはチケット）で在野の探索者を隊に招く仕組み。  
世界観的には召喚術じゃなくて「ギルドの封書」らしい。プレイヤー的にはガチャ。

---

## 基本ルール

| 項目 | 内容 |
|---|---|
| 値段 | 魔晶石 **500／単発** |
| 排出 | 助っ人プール（現行だいたい11体） |
| レア率（表示） | **★2 50%／★3 35%／★4 15%** |
| 初期5人 | アルド達は **出ない**（ストーリー枠） |
| ペット | ジャック達も **出ない** |
| 10連 | 今は無し。単発運用 |

チケットがあれば石を消費せず引ける（本番の配布は環境による）。

---

## 被ったらどうなる？

1. **限界突破**に変換（その助っ人が強くなる方向）  
2. あわせて **魔晶石が還元**される（★帯で量変わる目安: ★2→50／★3→100／★4→150）  
3. 限界突破上限に達したあとの重複は、だいたい **還元だけ**が続く

!!! tip "被り＝ゴミ、ではない"
    このゲーム、被りで限界突破するのが育成の一部。  
    新キャラだけ狙って石全振りより、**欲しい子の凸**も正義。

★3限界突破券（深層66など）があれば、引かずに凸だけ進められる。

## プールの顔ぶれ（現行）

| ★帯 | 例 | 職イメージ |
|---|---|---|
| ★4 | **ヴァルデン**（盾）、**火鷹**（剣） | 出たら環境が動く |
| ★3 | セリン、ルーシェ、シアン、ボルグ など | 支援・バッファ・回避盾 |
| ★2 | カイダ、ウォール、イヴァル、レノール、ネリ など | 条件付き火力・保険・ペットシナジー |

評価の雑感は[Tierランク](tier.md)。オミット（排出停止）の子はここでは扱わない。

## 石の使いどき（プレイヤー目線）

### 引いていいタイミング

- メインが詰まってて **別職・別パッシブ**が欲しい  
- セリン／ヴァルデン／シアンみたいな **周回・耐久枠**がいない  
- 日課で「招待1回」が出ていて、どうせ消化する  
- 深層99前に編成を厚くしたい

### まだ温存でいいタイミング

- 装備が白い（炉研ぎ前）なのに石だけ溶かす  
- ①序盤でまだ初期メンバーも育ってない  
- 「★4が出るまで」と無限単発（レートは15%。覚悟しろ）

!!! warning "ガチャより先にやれ"
    属性武器の炉研ぎ。だいたいこっちの方がクリア率上がる。

## よくある勘違い

| 勘違い | 実際 |
|---|---|
| 初期5人がガチャで出る | 出ない |
| ジャックをガチャで強化 | できない |
| 被りは完全損 | 凸＋還元がある |
| 10連がお得 | そもそも無い |
| ★高い＝即戦力 | 装備と属性が無いと弱い |

## 石の貯め方（超短縮）

潜行クリア（35〜65）が本給。調査・日課・深層マイルストーンがボーナス。  
詳細は[稼ぎ方](farming.md)。

500÷50 ≈ **クリア約10回分**が1回の目安（運次第）。
