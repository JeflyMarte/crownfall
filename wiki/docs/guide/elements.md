# 属性と状態異常

Crownfall の戦闘には、**属性** と **状態異常** がある。

| 体系 | 役割 |
|---|---|
| **属性** | 弱点で追加ダメージ、耐性で軽減。世界観上はエルダの相 |
| **状態異常** | 継続ダメージ・行動阻害・与／被ダメージ補正など |

---

## 属性 — 5種

| 属性 | id | 備考 |
|---|---|---|
| 炎 | `fire` | |
| 氷 | `ice` | |
| 電気 | `thunder` | 武器名では「雷」表記になることもある |
| 闇 | `dark` | 瘴気 |
| 聖 | `holy` | 浄化の光 |

### ダメージ補正

| 条件 | 倍率 |
|---|---|
| 攻撃属性が敵の **弱点** | **×1.25** |
| 攻撃属性が敵の **耐性** | **×0.75** |
| それ以外／無属性攻撃 | ×1.0 |

- **無属性**（属性が空）は弱点・耐性の対象外。
- **ダンジョンの「影響属性」**は、その属性攻撃が有利になる地形シナジーとして扱われる。

!!! warning "炎属性 ≠ 炎上"
    **炎属性** は弱点／耐性の倍率だけ。**炎上** は別物の状態異常（継続ダメージ）。

## 天候

探索開始時に天候が1つ決まる（**晴れ**のときは補正なし）。ギルド情報誌に天候枠があるときは効果も載る。

| 天候 | 主な補正（目安） |
|---|---|
| 雨 | 雷 +10%／炎 −5% |
| 夜 | 闇 +10%／聖 −5% |
| 霧 | 回復量 −15%／毒ダメージ +15% |
| 炎天 | 炎 +10%／氷 −5% |
| 吹雪 | 氷 +10%／炎 −5% |
| 晴れ | 補正なし（いちばん出やすい） |

調査地ごとに抽選の偏りがある（例: 霜寄り＝吹雪多め／霧沼＝霧多め）。情報誌で固定されているときはそちら優先。

---

## 主な状態異常

戦闘の時間単位は **1刻 ≈ 1.5秒**（効果の長さは刻数）。

| 状態 | 効果の目安 |
|---|---|
| 毒 | 継続ダメージ（攻撃力の影響あり・長めに薄い）。最大3スタック |
| 炎上 | 継続ダメージ（攻撃力の影響あり・短めに厚い）。最大3スタック |
| 出血 | 攻撃力割合の継続ダメージ。最大5スタック |
| 冷却 | 行動を50%スキップ |
| 感電 | 被ダメージ×1.15 ＋ 行動30%スキップ。最大2スタック |
| 鈍化 | 行動間隔が伸び、スキップしやすい |
| スタン | 行動を100%スキップ |
| 呪い | 与ダメージ×0.75 |
| 恐怖 | 行動を50%スキップ |
| 標的 | 被ダメージ×1.15 |
| 脆弱 | 被ダメージ×1.25 |
| 防御DOWN | 防御低下系 |
| 防御（guard） | 被ダメージ×0.5 |
| 鼓舞／小鼓舞 | 与ダメージアップ（味方） |
| 激昂 | 与ダメージ大幅アップだが被弾増（主に敵）。目安×1.4 |
| 相棒鼓舞 | ペットの与ダメアップ＋被ダメ軽減＋HP10%回復 |

付与源は武器のランダム補正、スキル、敵の被弾反撃、パッシブなど。

→ 敵ごとの弱点／耐性は[モンスター図鑑](../data/monsters.md)。
