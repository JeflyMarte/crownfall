# モーンゲート攻略

**王都地下モーンゲート** は、最初に挑む探索地。かつての首都・王都アステリアの地下に広がる遺構で、生物が遺物や鉱物を体内へ取り込む **鉱物化適応** が見られる。

各章は **1-1〜1-5**。ボス **セルディオン** は **1-5** のみ。

## 攻略の指針

!!! tip "属性を二段構えで"
    道中（炎弱点が多い）には **炎属性**、ボスには **電気または闇** が有効。隊で分担すると安定する。

!!! note "①ノーマルの密度"
    モーンゲート・ノーマルは群れが **最高2体**。ソロ敵は HP／ATK／SPD がやや厚め（×1.20。他章ソロの×1.50より弱い）。罠は部屋20%／探索5%程度。ボス召喚は Hard+ のみ。

- **炎枠** — 獣・昆虫寄りの雑魚を早く処理。特効が付いた個体ならさらに有利
- **電気／闇枠** — セルディオンと、電気弱点のエリート・一部雑魚
- **エリート** — クロックモスは被弾で状態異常を撒くことがある。前衛と回復・守りを意識
- **成長** — 推奨Lv3前後から挑戦可。ドロップと鍛冶で整えつつ 1-5 へ
- **クリア後** — 拠点で初期仲間の加入演出。**②ウィスパーウッドは①クリアで解禁**（調査ゲージ不要）。調査室は図鑑・完全調査景品用。アッシュ解放は **②調査100%**（①クリアだけでは出ない）
