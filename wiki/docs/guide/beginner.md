# 初心者向けガイド

「起動した。で、何する？」用。カジュアル版。堅い仕様書は[はじめに](getting-started.md)側。

## 最初の30分でやること

1. **イントロ適当に読む**（世界観好きならちゃんと読んで沼ってよい）
2. **隊長名決める**
3. **初期メンバー1人選ぶ**（迷ったら前衛寄りで安定。火力好きなら好きな顔でOK）
4. 拠点に着いたら **編成見て、モーンゲート 1-1 に潜る**

ここで止まらないこと。チュートリアル感のあとに「自動で探索が始まる」のが本体。

## 序盤ルート（これだけ覚えろ）

```
モーンゲートを周回
  → 炎武器／そこそこ防具を拾う
  → 鍛冶で炉研ぎ（とりあえず +2〜+3）＋余り同種で錬成（装備Lv）
  → ジャックをLv8前後まで育てて回復（つつき介抱）を覚える
  → 1-5 でセルディオン倒す
  → 拠点で仲間加入演出
  → ②ウィスパーウッド解禁（①クリアのみ）
  → 調査室は図鑑・完全調査景品用に回す（詰まったらここ）
```

!!! tip "初心者がやりがちなミス"
    - 属性無視で突っ込んで「弱い」判定する
    - 鍛冶触らずにガチャだけ回す（炉研ぎも錬成も放置）
    - 「調査しないと②が開かない」と思い込む（いまは不要）
    - 分解しまくってあとで「あの剣どこ？」となる
    - ジャックを放置して回復なしのままボスに突っ込む

!!! tip "序盤でダンジョンが勝てないとき"
    1. **調査室を回す** — 派遣でメンバーが育ち、完全調査景品の招待券で助っ人も増やしやすい。無理に連敗しない  
    2. **ペットの回復を待つ** — 序盤は回復が命。ジャックは **Lv8** で **つつき介抱**（最傷回復）を覚えるまで育てる  
    3. **錬成で装備Lvを上げる** — 炉研ぎだけでなく、余り同種を素材に本命の装備レベルを伸ばす  

詳細は[調査室](hub.md#調査室)／[ペット](pets.md)／[装備と鍛冶](equipment.md)。

## モーンゲートのコツ（超雑）

- 道中は **炎**が刺さりやすい
- ボス（セルディオン）は **電気／闇**
- だから「炎担当」と「ボス用の電気or闇」を隊に分けると楽
- エリートのクロックモスは鬱陶しい。雑に受けすぎない編成を

詳細は[モーンゲート攻略](mourngate.md)。

## 拠点で毎日ポチるもの

| やること | なぜ |
|---|---|
| **日課** | ゴールド／魔晶石のポイ活 |
| **イベントDG**（その曜日） | 日次1回。逃すとモッタイナイ |
| **調査室** | 詰まったら回す。育成EXP＋完全調査の招待券で助っ人増員 |
| **鍛冶** | 炉研ぎ＋**錬成**（装備Lv）。拾った同種余りは本命の餌 |
| **招待状** | 余裕のあるとき。調査券があれば石を温存できる |

情報誌（バナー）は放浪の予兆に加え、**天候**の枠があるときは効果も載る。暇なとき読むと世界が繋がる。

## 編成の雑な考え方

- 人間 **最大4人**＋ペット（ジャック）
- 前衛うすいと痛い。全部後衛も事故る
- スキルは1人1本装備が基本。入れ替え前提
- 「顔推し編成」はアリ。ただし属性と職の武器制限は裏切らない

ペットは装備不可。ジャックは最初からいる相棒枠。**Lv8のつつき介抱**が序盤の回復の要。あとでアッシュ／インク解放。詳しくは[ペット](pets.md)。

## 伸びないときのチェックリスト

1. 敵の弱点、見てる？（図鑑 or このWiki）
2. 炉研ぎ、してる？（+0放置は損）
3. **錬成**で装備Lv、上げてる？（本体Lvに対して低すぎない？）
4. ジャック、回復スキル覚えた？（つつき介抱＝Lv8）
5. 勝てないのに連敗してない？（調査室→助っ人増員のルート）
6. 職に合わない武器無理やり持たせてない？（持てない）
7. ①ボス倒したのに②タブが見えてないだけじゃない？（スクロール／再起動）

強さの伸ばし方まとめは[キャラを強くするには](power-up.md)。
