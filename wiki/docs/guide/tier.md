# キャラTierランク

プレイヤー雑感の **Tier表**。バランスパッチや所持装備でひっくり返る前提。  
「この子が絶対覇権」より **役割とパッシブが噛んでるか** の話だと思ってくれ。

!!! note "読み方"
    SS／S／A／B。未実装プール（オミット）は対象外。個人の推しは別腹でOK。

---

## 役割別ざっくり

### 殴り（DPS）

1. **アルド** — 初期最強クラスの安定火力。まずこれを育てて後悔しにくい  
2. **火鷹** — 雑魚処理が気持ちいい。ボス戦は鼓舞維持が課題  
3. **カイダ／レノール** — 条件付き・ガラス。使い手次第でS相当  
4. 助っ人ソードマン勢 — 装備と属性が揃えば誰でも刺さる

### 盾（タンク）

1. **ヴァルデン** — 環境の壁。いると編成が雑でも死ににくい  
2. **ガレン** — 反撃で「盾なのにDPSも出す」  
3. **ボルグ** — 回避タンク。運も絡むが楽しい  
4. **ガルム** — 保険。本盾というよりサブ

### 支援・回復

1. **セリン** — 周回の覇権ヒーラー感  
2. **シアン** — 攻めの支援（鼓舞）  
3. **エリアス** — 初期の命綱  
4. **ミラ** — デバフ支援

### オトモシナジー

| キャラ | なぜ |
|---|---|
| **ネリ** | ペット与ダメ+25%＆防御。オトモ特化ならトップクラス |
| **ミレイ** | ペット与ダメ+20%。初期なのにシナジー職の顔 |
| オトモ本体 | **ジャック**（初期）／**アッシュ**（守り・②調査100%）／**インク**（崩し・④調査100%） |

ミレイ＋ネリ両積みはオトモが主人公になる編成。好きならやっていい。

---

## Tierに入れないもの

- **顔推し** — 全部A以上扱いしてよい。このゲームは装備で底上げできる  
- **深層レジェンド持ち** — 武器側がTierを殴り上げる。キャラ単体表では測れない  
- **オミット助っ人** — 排出されないのでランク外
