# キャラTierランク

プレイヤー雑感の **Tier表**。バランスパッチや所持装備でひっくり返る前提。  
「この子が絶対覇権」より **役割とパッシブが噛んでるか** の話だと思ってくれ。

!!! note "読み方"
    SS／S／A／B。未実装プール（オミット）は対象外。個人の推しは別腹でOK。  
    固有パッシブは職テーマ再編後の現行（`builds.md` と同ソース）。

## 役割別ざっくり

### 殴り（DPS）

1. **アルド** — 初期最強クラスの安定火力（出血）。まずこれを育てて後悔しにくい  
2. **火鷹** — 雑魚処理が気持ちいい。ボス戦は鼓舞維持が課題  
3. **レノール** — 異常が乗った敵への砲台。ミレイ／アルドと組むと化ける  
4. **カイダ／ルーシェ** — 初撃バースト／吸血継戦。装備と手数で伸ばす  
5. 助っ人ソードマン勢 — 装備と属性が揃えば誰でも刺さる

### 盾（タンク）

1. **ヴァルデン** — 異常を弾く壁。毒・スタン帯で編成が雑でも死ににくい  
2. **ガレン** — 被ダメ減＋注目で「盾として噛む」  
3. **ボルグ** — 殴られたら殴り返すカウンター盾  
4. **ウォール** — 継続回復＋ヘイトのサブ。本盾というより隣

### 支援・回復・拘束

1. **セリン** — 戦闘中ピンチセーフのヒーラー感  
2. **シアン** — 拘束支援（冷却／鈍化／恐怖）  
3. **リーヴァ** — 標的で味方ダメ床上げ  
4. **エリアス** — 回復主軸ではなく属性火力（回復はスキル／セリン）

### ペット・状態異常

| キャラ | なぜ |
|---|---|
| **ネリ** | ペットステ×1.25＆終了時蘇生。ペット軸なら優先採用 |
| **ミレイ** | DoT撒き（毒／出血／炎上）。ペット強化ではない |
| ペット本体 | **ジャック**（初期）／**アッシュ**（火力・②調査100%）／**インク**（異常・④調査100%） |

ネリ＋ミレイ両積みは「ペット強化＋DoT着火」。レノールを足すと異常砲台パになる。

## Tierに入れないもの

- **顔推し** — 全部A以上扱いしてよい。このゲームは装備で底上げできる  
- **深層レジェンド持ち** — 武器側がTierを殴り上げる。キャラ単体表では測れない  
- **オミット助っ人** — 排出されないのでランク外
