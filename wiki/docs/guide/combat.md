# 戦闘の仕組み

戦闘は **自動** で進行する。指揮官は戦闘中に細かく操作せず、**事前の編成・装備・陣形・戦術** で結果を決める。

---

## パーティ構成

| 枠 | 内容 |
|---|---|
| **人間** | 最大4人。編成画面でスロットと前後列を決める |
| **オトモ** | 枠外の随伴。開始はジャック。アッシュ＝②調査100%、インク＝④調査100%で解放。編成のペット切替で1体のみ同行 |
| **装備スキル** | メンバーごとに装備できるスキルは原則1本（満枠時は付け替え） |
| **必殺** | 与ダメ／被ダメでゲージが溜まり、条件を満たすと発動 |

オトモは装備不可・常時前衛寄りの脅威を持つ。人間がいる限りタンク代わりにはなりにくいが、火力・守り・崩しの三角役割がある。

---

## 行動順

各ユニットの行動順は攻撃速度などを基にした **イニシアチブ** で決まり、高いほど早く動く。

- 味方 … 武器の攻撃速度 × ジョブ・装備補正
- 敵 … 敵データの攻撃速度

!!! tip "手数か、一撃か"
    **短剣・短刀・双刃** は手数が多く先手を取りやすい。**剣** は一撃が重い代わりに遅い傾向。

同じ値のときは味方が優先され、編成順で並ぶ。

---

## ダメージの決まり方

与ダメージは、おおむね次の要素から組み立てられる。

| 要素 | 効果 |
|---|---|
| **武器の攻撃力** | 基礎。個体のランダム補正・装備Lv・炉研ぎで伸びる |
| **ジョブ／レベル** | 成長で HP・攻撃などが上昇 |
| **クリティカル** | 一定確率で増加。武器・装飾・ランダム補正でクリ率が上がる |
| **敵の防御** | 与ダメを軽減 |
| **弱点／耐性** | 弱点 **×1.25**／耐性 **×0.75**（→[属性と状態異常](elements.md)） |
| **属性値** | 属性武器の「属性の強さ」が乗るとさらに伸びる |
| **特効（Bane）** | 特定の生態分類への追加倍率 |
| **状態異常** | 感電・標的などで被ダメ増、呪いなどで与ダメ減 |

---

## スキルと必殺

- **ジョブスキル／装備スキル** — クールダウンを持ち、戦闘中に自動発動
- **レジェンド等の固有効果** — パッシブ（常時／発火）。スキル枠とは別
- **属性が空のスキル** — **装備武器の属性を継承**する
- **必殺ゲージ** — 蓄積後に強力な行動。演出中はテンポが変わることがある

---

## 戦闘速度

設定で **×1**／**×1.5**／**×2** の3択（旧い ×0.75 は ×1 扱い）。

---

## 自動探索

ダンジョン入場後、隊は部屋を自動で進む。敵部屋で戦闘、勝利で次へ。罠・回復・宝箱などのイベント部屋もある。メインのボスは各 Biome の **×-5**。クリア後はリザルトで報酬を受け取る。

→ 敵の基礎値は[モンスター図鑑](../data/monsters.md)、進行全体は[進行とダンジョン](progression.md)。
