# ジョブ

探索隊メンバーの職能。**装備できる武器種**と習得スキルが異なります。一定レベルで上位職へ進化します。

## アルケミスト

*杖で魔法ダメージ・デバフに加え、回復と鼓舞で味方を支える支援役。*

| 項目 | 内容 |
|---|---|
| 役割 | support |
| 装備可能武器 | 杖 / 双刃 |
| 初期スキル | — |
| 習得スキル | アンブラボルト / 魔力弾 / 呪印 / 治癒 / 脆弱の粉 / 鼓舞 / 崩呪 / 大治癒 / 疫呪弾 / 極意呪 |
| 進化先 | セージ（Lv30）|
