# ダンジョンデータ

リソース上の基礎値。メインは各 Biome が **5章**（×-1〜×-5）に分かれ、ボスは原則 **×-5** のみ出現します。

!!! warning "寄り道／征討の扱い"
    **寄り道**はデータのみ残置（選択不可）。**征討**のうち `north_reach`／`red_forge_depths` はイベント常設で配信（メイン⑤ノーマル初回クリア後）。その他の征討は未解放。
